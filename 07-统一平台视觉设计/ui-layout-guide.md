### 1.2 代码结构（参考实现）

```tsx
// src/app/(admin)/layout.tsx - Admin Shell
'use client';
import { Layout, theme } from 'antd';
const { Header, Sider, Content } = Layout;

export default function AdminLayout({ children }: { children: React.ReactNode }) {
  const [collapsed, setCollapsed] = useState(false);
  const { token } = theme.useToken();

  return (
    <Layout style={{ minHeight: '100vh' }}>
      <AdminSider collapsed={collapsed} onCollapse={setCollapsed} />
      <Layout>
        <AdminHeader collapsed={collapsed} onToggle={() => setCollapsed(!collapsed)} />
        <Content style={{ margin: 24, minHeight: 280 }}>
          <Breadcrumb style={{ marginBottom: 16 }} />
          {children}
        </Content>
      </Layout>
    </Layout>
  );
}
```

### 3.2 数据卡片规范

| 属性 | 值 |
|------|-----|

### 4.3 搜索/筛选栏规范

| 元素 | 位置 | 说明 |
|------|------|------|
| 搜索框 | 左侧 | `Input.Search`，宽度 `240-320px` |
| 筛选下拉 | 搜索框右侧 | `Select`，宽度 `120-160px` |
| 日期选择 | 筛选下拉右侧 | `DatePicker` / `RangePicker` |
| 操作按钮 | 最右侧 | 主要操作（新增/导出等）|

### 4.4 表格规范

| 属性 | 值 |
|------|-----|
| 分页 | `pageSize: 20` |
| 选择 | 多选框列（左侧） |
| 操作列 | 右侧固定，`[编辑] [删除] [更多▼]` |
| 空态 | 显示 `Empty` 组件 + 引导文案 |
| 加载态 | `Spin` + Skeleton |
| 斑马纹 | 白色 + `rowHoverBg: #F9EEEE` |

### 5.2 表单规范

| 属性 | 值 |
|------|-----|
| 布局 | `vertical`（标签在输入框上方） |
| 标签颜色 | `#1A1A1A`，`font-weight: 500`，`font-size: 14px` |
| 间距 | 项间距 `24px` |
| 列数 | 默认 2 列，移动端 1 列 |
| 必填 | 红色 `*` + `rules: [{ required: true }]` |
| 错误提示 | 红色文字，`validateStatus: 'error'` |

### 5.3 弹窗 vs 页面

| 场景 | 方式 | 尺寸 |
|------|------|------|
| 新增/编辑单条数据 | Modal 弹窗 | `width: 600-720px` |
| 批量导入/配置 | Drawer 抽屉 | `width: 480px` |

## 8. 交互微动效

### 8.1 Framer Motion 集成

由于 `framer-motion` 已在 `package.json` 中安装，建议使用：

| 场景 | 动效 | 参数 |
|------|------|------|
| 页面切换 | fade + slideUp | `fadeInUp 0.3s` |
| 卡片 hover | scale + shadow | `scale(1.02)` + `shadow-md` |
| 列表行 hover | 背景过渡 | `background 0.15s` |
| 弹窗出现 | scale + fade | `scale(0.95) → 1` `opacity 0→1` |
| 数字动画 | 从 0 计数到目标值 | `countUp 1.5s ease-out` |
| Sidebar 展开/收起 | 宽度过渡 | `width 0.2s`, `Ant Drawer` |

### 8.2 示例

```tsx
import { motion } from 'framer-motion';

// 页面内容包裹
<motion.div
  initial={{ opacity: 0, y: 10 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.3 }}
>
  {children}
</motion.div>

// 统计卡片入场
<motion.div
  initial={{ opacity: 0, scale: 0.95 }}
  animate={{ opacity: 1, scale: 1 }}
  transition={{ duration: 0.2, delay: index * 0.1 }}
>
  <StatCard />
</motion.div>
```

## 9. 空状态 & 错误状态

| 场景 | 展示 | 组件 |
|------|------|------|
| 无数据 | 插画 + "暂无数据" + 操作引导 | `Empty` |
| 搜索无结果 | "未找到相关结果" + 清除搜索建议 | `Empty + Button` |
| 加载失败 | 错误提示 + 重试按钮 | `Result status="error"` |
| 无权限 | "您没有访问权限" + 联系管理员 | `Result status="403"` |
| 页面不存在 | "页面不存在" + 返回首页 | `Result status="404"` |
