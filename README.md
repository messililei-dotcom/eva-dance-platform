## ⚠️ 铁律：永远不要动云端数据库

**日期:** 2026-05-17
**来源:** 李校长明确指令

1. 每次 rsync 同步到云服务器时，**必须排除所有数据库文件**
2. 排除规则: `--exclude='dance.db*' --exclude='*.db'`
3. 只同步代码文件（.html/.js/.css/.json），绝不同步数据库
4. 云端数据库 = 生产数据，本地数据库 = 测试数据，二者严格隔离
5. 如需备份，先云端备份再操作，绝不覆盖
