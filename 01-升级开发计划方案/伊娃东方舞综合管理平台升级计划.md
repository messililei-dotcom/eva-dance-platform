```sql
-- 1. 订单表（统一网课+线下+商城）
CREATE TABLE Order (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    userId INTEGER NOT NULL,
    type TEXT NOT NULL,           -- course/product/membership
    amount REAL NOT NULL,
    status TEXT DEFAULT 'pending', -- pending/paid/refunded
    payment TEXT DEFAULT 'wechat',
    inviterId INTEGER,            -- 分销关系
    payTime TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 2. 订单明细表
CREATE TABLE OrderItem (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    orderId INTEGER NOT NULL,
    itemId INTEGER NOT NULL,
    itemType TEXT,                -- course/product
    price REAL,
    quantity INTEGER DEFAULT 1
);

-- 3. 商品表（舞蹈周边）
CREATE TABLE Product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    category TEXT,                -- 服装/书籍/器材/配件
    price REAL NOT NULL,
    stock INTEGER DEFAULT 100,
    description TEXT,
    image TEXT,
    status TEXT DEFAULT 'active'
);

-- 4. 课程授权表（网课）
CREATE TABLE CourseAuthorization (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    memberId INTEGER NOT NULL,
    courseId INTEGER NOT NULL,
    authType TEXT,                -- purchase/grant/admin
    authTime TEXT,
    expireTime TEXT,
    status TEXT DEFAULT 'active'
);

-- 5. 素材表
CREATE TABLE Material (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    type TEXT,                    -- video/image/document
    url TEXT,
    size INTEGER,
    folderId INTEGER,
    uploadTime TEXT,
    uploader TEXT
);

-- 6. 素材文件夹表
CREATE TABLE MaterialFolder (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    parentId INTEGER,
    path TEXT
);
```

### 2.2 课程管理 - 批量创建课程（参考荔枝微课后台）

**界面设计（根据李校长提供的网课系统截图）：**

```
┌─────────────────────────────────────────┐
│ 专栏管理 > 批量创建课程                    │
├─────────────────────────────────────────┤
│                                         │
│  【课程信息】                             │
│  课程名称: [________________]            │
│  课程简介: [________________]            │
│  课程封面: [点击上传/选择素材]            │
│                                         │
│  【视频上传】                             │
│  ┌─────────────────────────────────┐   │
│  │  拖拽视频到此处或点击上传          │   │
│  │  支持格式: MP4, MOV              │   │
│  │  单个文件最大: 2GB               │   │
│  └─────────────────────────────────┘   │
│                                         │
│  【选择已有素材】                         │
│  ┌─────────────────────────────────┐   │
│  │  📁 素材中心                      │   │
│  │  ├── 📁 2024春季课程              │   │
│  │  ├── 📁 基础入门                  │   │
│  │  └── 📁 进阶提升                  │   │
│  │       └── 🎬 进阶-第1课.mp4      │   │
│  └─────────────────────────────────┘   │
│                                         │
│  【批量设置】                             │
│  ☑️ 允许试看 [前3分钟]                   │
│  ☑️ 上架状态 [立即上架]                  │
│  ☑️ 课程排序 [自动排序]                  │
│                                         │
│  [取消]  [保存并继续]  [保存并上架]       │
│                                         │
└─────────────────────────────────────────┘
```

**核心功能：**
- **本地上传**：拖拽上传MP4/MOV格式视频，单个最大2GB
- **选择已有素材**：从素材中心选择已上传的视频
- **批量操作**：支持多选素材批量创建课程
- **课程设置**：试看时长、上架状态、排序规则
- **保存选项**：保存草稿 / 立即上架

**批量创建流程：**
```
1. 选择素材（本地上传 或 素材中心选择）
   ↓
2. 填写课程信息（名称、简介、封面）
   ↓
3. 设置课程属性（试看、上架状态、排序）
   ↓
4. 保存并上架 / 保存草稿
```

### 数据库新增表（分销系统）

```sql
-- 7. 分销关系表
CREATE TABLE DistributionRelation (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    inviterId INTEGER NOT NULL,
    inviteeId INTEGER NOT NULL,
    level INTEGER DEFAULT 1,
    bindTime DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 8. 分佣记录表
CREATE TABLE CommissionRecord (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    userId INTEGER NOT NULL,
    orderId INTEGER NOT NULL,
    amount REAL NOT NULL,
    level INTEGER,
    status TEXT DEFAULT 'pending',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 9. 邀请记录表
CREATE TABLE InviteRecord (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    inviterId INTEGER,
    inviteeId INTEGER,
    channel TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 分销核心逻辑

```
用户A分享链接 ?inviterId=A
    ↓
用户B点击注册 → 自动绑定（B → A）
    ↓
用户B下单支付 → 触发分佣
    ↓
A获得10%佣金
    ↓
如果A有上级C → C获得3%佣金
```
