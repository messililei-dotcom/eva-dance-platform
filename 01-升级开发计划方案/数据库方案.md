# 二、分销系统完整设计（核心赚钱模块）

---

## 🔥 1. 分销核心逻辑

### 👉 绑定关系（一次绑定，永久有效）

规则：

* 用户A分享链接
* 用户B点击并注册
* 建立：

```text
B → A（一级关系）
```

---

## 🔗 绑定逻辑

```text
条件：
- 新用户首次进入
- URL带 inviterId

执行：
- 写入 DistributionRelation
- 不可重复绑定
```

---

## 💰 分佣规则（建议初始版本）

| 类型   | 比例  |
| ---- | --- |
| 一级分销 | 10% |
| 二级分销 | 3%  |

---

## 💡 分佣计算逻辑

```text
订单支付成功 →

1. 找 inviter
2. 计算佣金
3. 写 CommissionRecord
```

# 四、分销核心算法（关键）

---

## 💻 伪代码（必须实现）

```javascript
async function handleCommission(order) {
    const inviter = await getInviter(order.userId);

    if (inviter) {
        const amount1 = order.amount * 0.1;

        createCommission({
            userId: inviter,
            amount: amount1,
            level: 1
        });

        const secondInviter = await getInviter(inviter);

        if (secondInviter) {
            const amount2 = order.amount * 0.03;

            createCommission({
                userId: secondInviter,
                amount: amount2,
                level: 2
            });
        }
    }
}
```
