体系 01

01_课程体系.md

伊娃东方舞课程体系不是单纯的成品舞教学，也不是传统动作模仿式教学，而是一套围绕身体开发、核心控制、技巧系统、音乐理解、编舞思维、舞台表达和艺术人格建立的长期成长体系。

训练 / 建设目标

  • 建立东方舞学习的完整路径
  • 帮助不同基础学员找到适合自己的课程入口
  • 明确基本功、技巧课、编舞课、现场课之间的关系
  • 避免碎片化学习和盲目囤课

核心模块

身体能力开发体系

呼吸、核心、体能、柔韧、稳定、肌肉控制、身体开发。它是所有技巧的根基，解决身体不会用、动作发飘、腰痛、无力等问题。

框架体系

手型、手位、手臂、头部、肩部、步伐、脚位。核心目标是先建立好看的身体，让学员跳任何舞都具备基本气质。

技巧体系

胯部、西米、八字、胸腰、甩发、旋转、复合技巧。核心不是轨迹，而是呼吸、发力、肌肉、空间和控制。

7+1技巧系统

以技巧为主线，加入呼吸、发力、形体、起范、空间、叠加和五感化表达。它解决动作单一、不会衔接、没有高级感的问题。

云弟子体系

对应整套教材的系统化课程，适合长期深度学习、教练成长和教学型老师完善知识结构。

编舞体系

从音乐结构、节奏逻辑、动作词汇、空间设计到即兴能力，帮助学员从舞者升级为创作者。

舞台表达体系

包含五感、起范、小范、舞台气场、审美、角色感和艺术人格。

常见错误

  • 把所有课程都当成成品舞课
  • 只想学结果，不愿意打身体基础
  • 忽略呼吸和核心，直接学高级技巧
  • 课程购买很多，但没有学习顺序
  • 把现场课用于学习本该在线上提前练好的基础内容

教学与运营要点

  • 零基础先建立呼吸、核心和框架，不建议一开始追求复杂技巧。
  • 有基础但动作不高级的学员，应优先补发力、胸腰、框架和7+1。
  • 老师型学员应重点补云弟子、编舞师、教学逻辑和课程结构。
  • 现场课应解决高价值问题，例如细节调整、作品表达、技巧整合和舞台表现。

应用场景

  • 课程顾问咨询
  • 学员学习路径规划
  • 线上课程体系搭建
  • 教练培训课程总纲
  • 智能客服课程推荐

体系 02

02_基本功体系.md

基本功不是压腿、下腰、记动作，而是身体控制能力。伊娃体系中的基本功包括呼吸、核心、肌肉控制、稳定性、身体连接、形体、空间感、节奏控制、协调性和重心控制。

训练 / 建设目标

  • 让身体具备跳舞的基础条件
  • 建立稳定、分离、连接和控制能力
  • 减少腰痛、关节代偿和错误发力
  • 为后续技巧、成品舞和舞台表达打底

核心模块

呼吸基本功

通过腹式、肋式、胸式呼吸建立深层核心和身体空间。

核心基本功

上核心控制胸腰和上半身，下核心控制骨盆、胯和下盘。

肌肉控制

训练收、放、推、提、延伸、击控、分离与稳定。

形体基本功

背肌、肩线、手臂、头部和身体线条的基础建设。

稳定性基本功

中轴、足底、重心、核心四类稳定，是技巧安全和质量的前提。

协调基本功

手脚协调、呼吸协调、身体协调、节奏协调，让动作不断层。

常见错误

  • 只练动作轨迹，不练身体能力
  • 只练软开，不练核心和肌肉控制
  • 一开始就学复杂成品舞
  • 练习时没有呼吸，导致动作死、腰痛、身体僵
  • 忽略背肌、手臂、头部等形体基础

教学与运营要点

  • 基本功教学要从身体感受开始，而不是从外形模仿开始。
  • 每一个基本功动作都要说明发力来源、呼吸方式、肌肉参与和常见错误。
  • 基础训练应可重复、可检测、可纠正。
  • 基本功不是低级课程，而是决定高级感的长期系统。

应用场景

  • 零基础入门课
  • 每日带练课
  • 线下集训预备课
  • 教练训练SOP
  • 学员体测与分层

体系 03

03_呼吸训练体系.md

呼吸是伊娃东方舞体系的根基。它不是简单吸气吐气，而是深层肌肉启动、核心建立、身体连接、力量传导和情绪表达的入口。

训练 / 建设目标

  • 建立上核心、下核心和中段连接
  • 让动作有气口、有节奏、有生命力
  • 解决腰痛、身体僵硬、动作断层问题
  • 让高级技巧具备安全和控制基础

核心模块

腹式呼吸

训练下腹、盆底和下核心，帮助稳定骨盆和胯部动作。

肋式呼吸

训练侧腰、肋骨打开和横向空间，让身体不再平面化。

胸式呼吸

训练提胸、上核心、胸腔空间和背肌启动。

呼吸与核心

吐气收上腹，夹臀提下腹，上下连接形成完整核心。

呼吸与发力

呼吸先启动，再由核心传导到胯、腿、手臂、头部。

呼吸与舞感

呼吸形成动作之间的气口、停顿、层次和情绪。

常见错误

  • 把呼吸练成单纯鼓肚子
  • 跳舞时憋气
  • 只用胸、不用肋和腹
  • 只会收腹，不会夹臀和连接下核心
  • 动作与呼吸脱节，导致身体断层

教学与运营要点

  • 呼吸课要先让学员感受到身体内部变化。
  • 教学中应把呼吸和具体动作连接，例如圆胯、骆驼、胸腰、甩发。
  • 呼吸练习应从慢到快，从静态到动态，从单一到复合。
  • 老师要不断提醒：呼吸不是装饰，而是发力入口。

应用场景

  • 呼吸专项课
  • 核心训练课
  • 腰痛问题答疑
  • 7+1前置课
  • 高阶技巧安全训练

体系 04

04_核心发力体系.md

核心发力是身体深层肌肉的精准连接与控制。东方舞的发力不是猛用力，而是通过呼吸、收腹、夹臀、核心连接和肌肉传导形成稳定、流动、连续的动作。

训练 / 建设目标

  • 建立正确发力链条
  • 避免髋关节、腰椎、脖子等部位代偿
  • 让动作稳定、细腻、丝滑、有力量
  • 提升击控、分离、旋转、甩发、西米等技巧质量

核心模块

上核心

通过吐气、收肋、收上腹建立，控制胸腰、手臂和上半身稳定。

下核心

通过夹臀、盆底肌、下腹收紧建立，控制骨盆、胯和下盘。

中段连接

上核心与下核心形成一整段连接，让身体不断层。

腿部发力链

呼吸 → 收腹 → 夹臀 → 髋周稳定 → 腿部延伸。

胯部发力链

核心稳定后由骨盆和髋周肌肉带动，而不是直接甩髋。

复合技巧发力

在旋转、甩发、撩腿、西米等动作中保持核心稳定和持续连接。

常见错误

  • 只收腹，不连接臀腿
  • 用髋关节硬抬腿
  • 用腰代偿胯部动作
  • 甩发只用脖子
  • 动作之间发力断层
  • 追求幅度而失去控制

教学与运营要点

  • 讲发力必须讲肌肉和路径，不能只喊用力。
  • 每个动作都要拆出起点、传导、结果。
  • 先慢练，让学员感受到核心连接，再加速度、节奏和空间。
  • 教学中要用对比法：错误发力和正确发力并列示范。

应用场景

  • 发力纠错课
  • 腰痛问题诊断
  • 撩腿与圆胯训练
  • 西米控制训练
  • 教练发力语言标准化

体系 05

05_框架技巧体系.md

框架是身体整体结构与舞蹈气质的建立。它不是摆姿势，而是通过头、肩、背、胸腰、手臂、脚位、步伐和空间共同形成舞者的身体美学。

训练 / 建设目标

  • 建立高级形体和舞蹈气质
  • 让身体不散、不塌、不僵
  • 让简单动作也有气场和高级感
  • 为技巧和舞台表达提供外在结构

核心模块

大框架

背肌、胸腰、肩线、中轴、身体空间，决定整体气场。

小框架

头部、手型、手指、眼神、肩部细节，决定精致度和味道。

头部框架

头部方向、留头、转头、点头，让身体有灵气。

肩背框架

肩部打开下沉，背肌支撑手臂和胸腰。

手臂框架

从背肌到指尖的完整延伸，形成空间线条。

脚位与步伐框架

脚位决定重心，步伐决定舞台空间。

常见错误

  • 肩膀耸起
  • 背肌塌掉
  • 手臂只靠手在摆
  • 头部不参与动作
  • 脚位混乱导致重心不稳
  • 身体没有空间维度

教学与运营要点

  • 框架课要把站姿、背肌、肩线、手臂、头部作为整体训练。
  • 先建立稳定静态框架，再加入动作、步伐和节奏。
  • 框架不是僵硬保持，而是有呼吸、有空间的动态结构。
  • 训练时要强调头、手、胸腰、重心的连接。

应用场景

  • 形体提升课
  • 舞蹈气质训练
  • 零基础框架入门
  • 成品舞高级感纠错
  • 教练基础课标准

体系 06

06_胸腰技巧体系.md

胸腰是东方舞高级感的重要来源，它不是弯腰、顶胸或身体波浪，而是呼吸、上核心、背肌、肋骨、腰部控制和空间延展共同形成的身体能力。

训练 / 建设目标

  • 建立上半身空间和延展感
  • 提升舞蹈高级感、女人味和流动感
  • 支持旋转、甩发、手臂、骆驼等技巧
  • 改善塌胸、身体平、动作死的问题

核心模块

胸式呼吸

帮助打开胸腔，建立上核心和提胸能力。

肋骨空间

肋式呼吸让身体具备横向空间和侧腰控制。

背肌启动

背肌支撑胸腰，避免腰部硬折。

胸腰分离

训练胸、肋、腰的分层控制。

胸腰连接手臂

胸腰带动背肌，背肌带动手臂，手臂延伸到指尖。

胸腰连接甩发

胸腰提供甩发动力和轨迹的身体来源。

常见错误

  • 硬折腰
  • 只顶胸不提背
  • 没有呼吸
  • 只追求幅度
  • 腰部代偿
  • 胸腰和手臂、头部脱节

教学与运营要点

  • 胸腰教学要先建立提拉感，而不是下压感。
  • 每次胸腰动作都应说明吸气、延展、背肌和空间。
  • 胸腰可以连接手臂、头部、甩发和旋转，避免孤立训练。
  • 要强调胸腰的美感来自空间，而不是幅度。

应用场景

  • 胸腰专项课
  • 高级感提升课
  • 甩发前置训练
  • 手臂线条训练
  • 形体气质课

体系 07

07_头部技巧体系.md

头部技巧是东方舞灵气、五感和舞台感的重要来源。头不是孤立运动，而是由核心、胸腰、背肌、呼吸带动的空间延伸。

训练 / 建设目标

  • 让动作拥有灵气和方向感
  • 解决头部僵硬、缩脖子、头掉下去的问题
  • 建立留头、点头、转头和头发轨迹基础
  • 增强舞台表现与五感表达

核心模块

头部方向

通过前后、左右、斜线、圆形方向建立空间意识。

留头

身体先走，头最后离开，形成视觉延迟和高级感。

点头

训练小框架、节奏点和灵气。

转头

连接空间方向、眼神和身体路线。

头部与胸腰

胸腰和背肌支撑头部，让头是拎出去而不是掉出去。

头部与手臂

头的方向与手臂延伸形成完整画面。

常见错误

  • 甩脖子
  • 缩脖子
  • 头和身体一起走，没有留头
  • 头部没有方向
  • 头部和眼神分离
  • 头部动作没有呼吸

教学与运营要点

  • 先练头部稳定和延伸，再练速度和轨迹。
  • 留头训练要配合转身、步伐和旋转。
  • 头部教学不能只讲头，要讲胸腰、背肌和核心。
  • 头部动作要与眼神、手臂和音乐气口统一。

应用场景

  • 头部专项课
  • 甩发前置课
  • 舞台表现训练
  • 成品舞五感提升
  • 旋转留头训练

体系 08

08_甩发技巧体系.md

甩发是东方舞高阶表现技巧，不是乱甩头发，而是身体、呼吸、核心、胸腰、节奏、空间和情绪的综合表达。

训练 / 建设目标

  • 建立安全、稳定、有控制的甩发能力
  • 让甩发具备音乐性、空间感和情绪爆发
  • 避免脖子代偿和头部失控
  • 提升舞台视觉冲击力

核心模块

中轴稳定

甩发时身体不能飞，核心和足底必须稳定。

胸腰动力

甩发动力来自胸腰和背肌，不是脖子。

留头技巧

身体先走，头最后离开，形成甩发高级感。

头发轨迹

圆、半圆、横线、斜线、螺旋等轨迹要清晰。

节奏与气口

甩发需要拍点、停顿、爆发和收回。

情绪表达

甩发不只是技巧，而是音乐情绪和女性力量的爆发。

常见错误

  • 只用脖子甩
  • 核心不稳导致身体飞
  • 没有胸腰
  • 不会留头
  • 头发乱飞没有轨迹
  • 只追求大和猛

教学与运营要点

  • 甩发前必须检查核心、胸腰、足底和头部控制基础。
  • 先练慢轨迹，再练速度和爆发。
  • 每个甩发都要有起点、路线、落点和情绪。
  • 不建议基础弱的学员直接练高强度甩发。

应用场景

  • 甩发专项课
  • 舞台冲击力训练
  • 高阶技巧集训
  • 头部技巧进阶
  • 作品高潮段落训练

体系 09

09_旋转技巧体系.md

旋转不是简单转圈，而是中轴、核心、重心、足底、胸腰、呼吸、留头、节奏和空间控制的综合能力。

训练 / 建设目标

  • 建立稳定中轴和脚下功夫
  • 提升平转、定点转、空间转等技巧质量
  • 让身体在旋转中保持轻、稳、长
  • 避免晕、飘、偏轴和重心失控

核心模块

中轴

头、胸、核心、骨盆、支撑腿形成一条稳定轴线。

足底

抓地、推地、稳定、传导，是旋转基础。

重心

不同脚位对应不同重心，重心清晰才不乱。

核心

稳定身体，防止散架和腰部代偿。

胸腰提拉

胸腰和背肌提起来，旋转会更轻。

留头

帮助稳定方向、减少眩晕、增强高级感。

常见错误

核心与夹臀

11_西米技巧体系.md

西米是东方舞最具代表性的技巧之一。它不是乱抖，也不是单纯追求速度，而是核心、臀腿、骨盆、重心、节奏、击控、呼吸和身体分离的综合能力。

  • 让西米有节奏、有层次、有持续性

核心模块

核心稳定

没有核心，西米一定散。

臀腿支撑

西米不是胯自己抖，而是下盘在控制。

骨盆控制

骨盆稳，西米才清晰。

重心管理

双脚、单脚、行走、转圈西米都需要不同重心。

击控能力

每一下都清楚，而不是糊成一片。

分离能力

下半身西米，上半身仍能表达。

音乐层次

西米要有轻重、气口、节奏变化。

12_手臂技巧体系.md

手臂是东方舞气质和线条的重要来源。真正高级的手臂不是摆手，而是背肌、胸腰、肩部、呼吸、空间、节奏和情绪的延伸。

训练 / 建设目标

  • 让手臂与头部、胸腰、步伐和音乐统一
  • 提升舞蹈气质和高级感

核心模块

背肌来源

手臂从背里长出来，背肌决定手臂长度和气质。

肩部控制

肩要打开、下沉、稳定，避免耸肩。

胸腰连接

胸腰带动背肌，背肌带动手臂到指尖。

掌指腕

掌决定气场，指决定精致，腕决定流动。

肘部连接

肘连接肩、臂、腕，避免手臂断层。

手臂与头部

头有方向，手有延伸，形成完整画面。

手臂与节奏

手臂也要唱音乐，有气口和层次。

常见错误

  • 只摆手
  • 耸肩
  • 手腕断

  • 手臂没有呼吸
  • 只有手没有背
  • 手和头部不连接

教学与运营要点

  • 手臂教学不能从手开始，而要从背肌和胸腰开始。
  • 掌、指、腕、肘、臂要拆开训练再整体连接。
  • 手臂要和呼吸、头部、眼神、音乐同步。
  • 训练中要让学员感受到手臂的空间方向和延伸路径。

应用场景

13_步伐体系.md

步伐是舞蹈从原地动作走向空间表达的基础。真正的步伐不是换脚或移动，而是重心、足底、核心、空间、节奏、呼吸和身体连接的综合体系。

训练 / 建设目标

  • 建立稳定清晰的移动能力
  • 让学员从原地动作进入舞台空间

  • 提升成品舞、编舞和舞台调度能力

核心模块

脚位

一位、二位、三位、四位、五位、六位、七位脚决定不同重心。

重心

步伐本质是重心转换，不是脚乱换。

足底

抓地、推地、缓冲、稳定，让身体有根。

核心

移动中保持身体不断层。

空间方向

前后、左右、斜线、圆形、舞台路线。

手脚协调

脚控制重心，手控制空间，身体形成整体流动。

步伐与音乐

每一步都有拍点、轻重、气口和节奏变化。

常见错误

  • 脚下没力

  • 没有呼吸

  • 走位没有空间设计

  • 教学中要让学员理解舞台方向和观众视角。

应用场景

14_编舞体系.md

编舞不是拼动作，而是音乐、身体、空间、节奏、情绪和艺术逻辑的综合创作。它要求舞者听懂音乐、理解结构、掌握动作词汇并具备空间与情绪设计能力。

训练 / 建设目标

  • 帮助学员从动作学习者升级为创作者
  • 建立音乐理解和节奏逻辑
  • 提升组合编排、作品创作和即兴能力
  • 形成更高级的舞蹈审美和作品判断力

核心模块

音乐结构

前奏、主歌、副歌、过渡、高潮、收尾，决定作品起承转合。

节奏体系

打拍、数拍、重拍、切分、花音以及中东节奏识别。

动作词汇

技巧、步伐、手臂、空间变化构成编舞词汇。

空间设计

前后、左右、高低、斜线、圆形、舞台调度。

情绪层次

情绪推进、能量变化、角色表达和音乐情感。

即兴能力

在音乐逻辑和身体词汇基础上的即时创作。

审美判断

判断一个作品是否有结构、空间、层次、呼吸和高级感。

常见错误

  • 只拼动作
  • 听不懂音乐
  • 动作太满没有留白
  • 没有空间变化
  • 没有情绪推进
  • 只会模仿不会创作
  • 即兴变成乱跳

教学与运营要点

  • 编舞课要先从听音乐开始，而不是直接排动作。
  • 要训练学员听节奏、乐器、花音和音乐结构。
  • 编舞应同时考虑动作、空间、情绪和舞台。
  • 即兴训练必须建立在系统逻辑上。

应用场景

  • 编舞师课程
  • 教师进阶培训
  • 作品创作训练
  • 即兴能力训练
  • 比赛作品打磨
