# SWOD 课程学习权益与展示规则

本规则适用于官网、PWA、微信小程序及各原生 App 的线上课程、成品舞学习课程。全系统复用统一后台的有效学习授权；线下课程期次和商城商品不得用与线上课相同的数字 ID 推断为已购买。

## 文案和入口

- 个人中心课程栏目名称：**我的课程**。
- 登录后确实拥有当前课程有效学习权限：隐藏售价、优惠价、原价和购买入口，课程卡片统一显示绿色 **✓ 已解锁**。
- 已解锁课程的操作入口：**立即学习**或**继续学习**；个人中心统一使用**继续学习**，直接进入课程目录，续播位置仍遵循原有学习记录。
- 未登录或没有有效权益：正常展示售价、优惠价、原价及购买入口。免费试看、免费课程、已创建但未支付的订单不能冒充已购买课程。
- 价格展示与课程权限必须通过课程的后台 series ID 关联，历史官网 ID 必须先映射，不得把同号历史课程、线下期次或商品当成同一门课程。

## 权限和安全

1. 服务端使用已验证登录凭证取得用户 ID。请求参数中的 member_id、前端缓存中的 unlocked 或订单完成页提示不能作为授权凭证。
2. 课程列表的已解锁判断复用 `/member/authorized-series`。该列表仅包含服务端认定为 active、未过期且已发布的课程授权。
3. 进入播放时再次检查当前用户、当前课程/课节及有效期，未经授权不能获得受保护的播放地址；改前端标记不能绕过此检查。
4. 交易创建仍由服务端校验身份、课程、金额和重复购买，前端隐藏价格不代替服务端验证。
5. 用户权益响应应为 private/no-store，不能混入公共课程目录的共享缓存或分享卡片。
6. 登录、退出、切换账号、支付返回和页面重新显示时刷新权益。异步返回必须核对当前账号，不能使用上一个账号的响应。官网与 iOS 活跃时另定期刷新。
7. 查询失败不能假称已解锁，也不能立即引导重复购买；提示刷新重试。

## 验收

同时检查游客、未购买、有效授权、过期、撤销、其他账号、接口失败、账号切换、直达详情/旧购买地址，以及首页、列表、搜索、详情、个人中心中的展示与操作。付费课节的服务端鉴权需要独立验证。

本规则不自动开放或修改各应用商店的平台支付政策，也不更改小程序视频总开关。代码同步、构建测试、部署、上传和发布分别记录，不互相替代。
