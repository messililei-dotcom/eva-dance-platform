# 舞蹈学员管理系统产品开发文档

## 1. 项目概述

### 1.1 项目背景
随着舞蹈教育行业的快速发展，传统的人工管理模式已无法满足日益增长的管理需求。舞蹈学校面临着学员信息管理复杂、缴费记录混乱、课程安排困难等问题。为提高管理效率，降低运营成本，特开发此舞蹈学员管理系统。

### 1.2 项目目标
- **提高管理效率**：通过数字化手段简化日常管理工作
- **降低人力成本**：减少人工记录和统计的工作量
- **提升服务质量**：为学员提供更好的服务体验
- **数据驱动决策**：通过数据分析辅助经营决策

### 1.3 项目范围
本系统涵盖舞蹈学校的核心业务流程，包括学员管理、课程管理、缴费管理、核销管理等功能模块，支持多角色协同办公。

## 2. 需求分析

### 2.1 业务需求
#### 2.1.1 核心业务流程
1. **学员注册**：录入学员基本信息，建立学员档案
2. **课程安排**：设置课程类型、价格、时间等信息
3. **缴费管理**：记录学员缴费情况，管理课程费用
4. **核销管理**：跟踪课程消耗情况，管理剩余课时
5. **统计分析**：生成各类经营数据报表

#### 2.1.2 业务特点
- **多课程类型**：支持集训课、次卡课、年卡、传承弟子班等多种课程形式
- **灵活定价**：不同课程类型有不同的定价策略
- **课时管理**：精确跟踪每次课时消耗情况
- **奖励机制**：为签约教师设置不同课程类型的奖金比例

### 2.2 用户需求
#### 2.2.1 管理员需求
- 系统设置和用户管理
- 奖金比例设置
- 操作日志查看
- 数据统计分析

#### 2.2.2 店长需求
- 业务流程管理
- 员工账户创建
- 数据查看和统计
- 业绩跟踪

#### 2.2.3 签约教师需求
- 日常业务操作
- 学员信息查看
- 缴费和核销操作
- 个人业绩查看

### 2.3 功能需求
#### 2.3.1 学员管理
- 学员信息录入、编辑、查询
- 学员等级分类管理
- 学员状态跟踪
- 学员历史记录查看

#### 2.3.2 课程管理
- 课程信息设置
- 课程类型管理
- 价格和课时设置
- 有效期管理

#### 2.3.3 缴费管理
- 缴费记录录入
- 支付方式管理
- 签约教师记录
- 发票信息管理

#### 2.3.4 核销管理

## 4. 数据库设计

### 4.1 概念模型
系统包含6个核心实体：
- User (用户)：系统用户信息
- Member (学员)：学员基本信息
- Course (课程)：课程相关信息
- Payment (缴费)：缴费记录信息
- ConsumeRecord (核销)：核销记录信息
- OperationLog (日志)：操作日志信息

### 4.2 逻辑模型

#### 4.2.1 User 表 (用户表)
```sql
CREATE TABLE User (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,        -- 用户名
    password TEXT NOT NULL,               -- 加密密码
    name TEXT NOT NULL,                   -- 真实姓名
    role TEXT DEFAULT 'teacher',          -- 角色 (admin/manager/teacher)
    bonusTraining REAL DEFAULT 10,        -- 集训课奖金比例
    bonusCard REAL DEFAULT 5,             -- 次卡课奖金比例
    bonusYearly REAL DEFAULT 8,           -- 年卡奖金比例
    bonusDisciple REAL DEFAULT 15,        -- 传承弟子班奖金比例
    status TEXT DEFAULT 'active',         -- 状态 (active/disabled)
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 4.2.2 Member 表 (学员表)
```sql
CREATE TABLE Member (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                   -- 学员姓名
    phone TEXT,                           -- 手机号
    gender TEXT DEFAULT '女',              -- 性别
    birthday TEXT DEFAULT '',              -- 生日
    level TEXT DEFAULT '体验学员',          -- 等级 (体验学员/普通学员/VIP学员)
    remark TEXT DEFAULT '',                -- 备注
    register_date TEXT DEFAULT '',         -- 登记日期
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 4.2.3 Course 表 (课程表)
```sql
CREATE TABLE Course (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                   -- 课程名称
    type TEXT NOT NULL,                   -- 课程类型 (集训课/次卡课/年卡/传承弟子班)
    price INTEGER NOT NULL,               -- 价格
    startDate TEXT,                       -- 开始日期
    endDate TEXT,                         -- 结束日期
    sessions INTEGER DEFAULT 10,          -- 课时数
    validDays INTEGER,                    -- 有效期(天)
    teacher TEXT,                         -- 授课老师
    content TEXT,                         -- 课程描述
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 4.2.4 Payment 表 (缴费记录表)
```sql
CREATE TABLE Payment (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    memberId INTEGER NOT NULL,            -- 学员ID
    memberName TEXT NOT NULL,             -- 学员姓名
    memberPhone TEXT DEFAULT '',          -- 学员手机号
    courseId INTEGER NOT NULL,            -- 课程ID
    courseName TEXT NOT NULL,             -- 课程名称
    amount INTEGER NOT NULL,              -- 金额
    date TEXT NOT NULL,                   -- 缴费日期
    payment TEXT DEFAULT '微信',           -- 支付方式
    sales TEXT DEFAULT '',                -- 签约教师
    remark TEXT DEFAULT '',               -- 备注
    expireDate TEXT DEFAULT '',           -- 到期日期
    remainingSessions INTEGER DEFAULT 0,  -- 剩余课时
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 4.2.5 ConsumeRecord 表 (核销记录表)
```sql
CREATE TABLE ConsumeRecord (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    memberId INTEGER NOT NULL,            -- 学员ID
    memberName TEXT NOT NULL,             -- 学员姓名
    courseId INTEGER NOT NULL,            -- 课程ID
    courseName TEXT NOT NULL,             -- 课程名称
    count INTEGER DEFAULT 1,              -- 核销次数
    consumeDate TEXT NOT NULL,            -- 核销日期
    remainingAfter INTEGER,               -- 核销后剩余课时
    operator TEXT,                        -- 操作人
    remark TEXT,                          -- 备注
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 4.2.6 OperationLog 表 (操作日志表)
```sql
CREATE TABLE OperationLog (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    time TEXT NOT NULL,                   -- 操作时间
    operator TEXT NOT NULL,               -- 操作人
    type TEXT NOT NULL,                   -- 操作类型 (登录/新建/编辑/删除/核销)
    module TEXT NOT NULL,                 -- 操作模块
    detail TEXT                           -- 操作详情
);
```

### 4.3 数据库约束
- 主键约束：每个表都有自增主键
- 唯一约束：用户名唯一
- 非空约束：关键字段不能为空
- 外键约束：相关表之间建立外键关系
