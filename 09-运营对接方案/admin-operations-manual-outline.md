## 一、手册定位与使用说明

### 1.1 手册目标
- 为运营团队提供统一后台的标准化操作指引
- 确保不同角色（店长/前台/老师）按统一规范操作
- 降低培训成本，提升日常运营效率

### 1.2 适用角色

| 角色 | 主要功能模块 | 手册章节 |
|------|------------|---------|
| 🏪 店长（伊琳） | 全模块 | 全部 |
| 🧑‍💼 前台/行政 | 学员管理、订单处理 | 第二~四章 |
| 👩‍🏫 签约老师 | 学员查看、课时核销 | 第三章 |
| 💰 财务 | 订单对账、财务报表 | 第六章 |

### 1.3 使用建议
- 新员工入职时通读手册 → 系统实操练习 → 老员工带教3天
- 手册按模块独立成章，可选择性阅读
- 定期更新（平台每上线新功能时同步更新）

### 3.2 👤 学员管理

**功能说明：** 学员档案管理、课时核销、信息查询

#### 3.2.1 学员列表


**操作要点：**
- 搜索支持手机号（精确）和姓名（模糊）

- 手机号已存在 → 系统提示"该手机号已注册"，可跳转到现有学员档案

#### 3.2.4 课时核销（签约老师高频操作）

**标准流程：**
1. 打开「学员管理」→ 搜索学员
2. 进入学员详情 → 点击「核销」
3. 选择课程 → 填写核销课时数
4. 确认 → 系统自动记录操作日志

**批量核销（班级场景）：**
1. 进入「课程管理」→ 选择课程 → 选择节次
2. 勾选已到课学员
3. 批量核销（可选：短信通知学员核销结果）

**⚠️ 核销注意事项：**
- 剩余课时≥0才能核销
- 核销后不可撤回（需联系店长处理）
- 建议当日课后立即核销，避免遗忘

### 3.4 🛒 订单管理

**功能说明：** 订单查询、退款处理、发货管理

**订单状态流转：**


**订单列表筛选：**

**退款处理流程（店长权限）：**
1. 搜索订单 → 进入订单详情
2. 点击「发起退款」→ 填写退款金额 + 退款原因
3. 确认 → 系统自动发起退款（微信/支付宝）
4. 退款完成 → 订单状态更新为「已退款」

**⚠️ 退款注意事项：**
- 学员线下缴费（现金/转账）→ 线下自行退款，系统做退款标记
- 线上支付退款 → 原路退回（T+0到账）
- 部分退款：支持只退部分金额
- 退款后自动解除课程授权

## 四、常见问题处理流程

### 4.1 学员忘记手机号/无法登录

**处理流程：**
1. 前台在「学员管理」搜索学员姓名
2. 确认学员身份 → 核实手机号
3. 告知学员手机号（或短信发送）
4. 如手机号已更换 → 协助修改手机号
5. 指导学员通过短信验证码登录

### 4.2 线下缴费后线上未显示

**处理流程：**
1. 在「订单管理」搜索学员姓名
2. 确认是否有手动补录
3. 如未补录 → 「订单管理」→ 点击「新增订单」
4. 选择学员 → 选择课程 → 填写缴费金额 + 支付方式（现金/转账）
5. 提交 → 自动关联课程授权
6. 告知学员可登录查看

### 4.3 学员要求退课/退款

**处理流程：**
1. 核实剩余课时/使用状态
2. 判断是否在退课期限内
3. ⚠️ **红线原则：** 
   - 已消耗课时 ≥ 总课时的1/3 → 原则上不予退款（特殊情况需店长审批）
   - 未消耗课时 ≤ 总课时的1/3 → 按剩余价值退款
4. 线上支付 → 发起系统退款
5. 线下支付 → 线下退款 + 系统标记已退款
6. 通知客服同步处理客诉单

### 4.4 学员课时核销错误

**处理流程：**
1. 核实核销记录（操作日志可查操作人）
2. 店长登录 → 进入学员详情 → 核销记录
3. 点击「撤销核销」（店长权限）
4. 重新核销正确课时
5. 记录操作异常原因

### 4.5 分销佣金纠纷

**处理流程：**
1. 查询佣金记录（分佣明细）
2. 确认订单关联的分销关系
3. 如系统计算错误 → 生成手工调整单（店长审批）
4. 如正常但有争议 → 说明分佣规则
5. 争议升级 → 转交给店长/李校长处理
