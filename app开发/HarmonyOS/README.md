## 本机构建（2026-10-23）

终端环境配置位于 `~/.config/swod/harmony-env.sh`，已接入 `~/.zshrc`；执行脚本前可先 `source ~/.config/swod/harmony-env.sh`。使用 `python3 EvaDance/scripts/build_release.py` 可在本机缓存目录隔离编译、调用官方工具签名与验签、生成发布候选包。脚本仅从本机受控目录读取签名材料，不把私钥或密码复制入工程及发布包。

构建日志中“无 signingConfig”表示第一阶段产生未签名 HAP；随后独立的官方签名与验签步骤才产出交付文件，以 `verification.json` 和 `evidence/verify-hap.log` 为证。发布 Profile 的分发类型为 `app_gallery`；侧载真机调试仍需合适的调试/指定设备 Profile 和真机验收。

工具实际启动检查可运行 `python3 EvaDance/scripts/check_debug_tools.py`，包含 hdc 版本、设备数量和模拟器版本查询，均带超时限制。模拟器实例为 `SWOD_API22`（最终包复验）和 `SWOD_API24`（阅读功能对照），当前仅 API22 运行。使用官方 CLI `Emulator -start SWOD_API22 -bootmode coldboot` 启动，连接目标以 `hdc list targets -v` 的实际结果为准。模拟器调试包无发布签名，不能作为真实手机分发包。
