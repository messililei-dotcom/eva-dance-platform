# Android 开发资料

更新：2026-10-14。原生 Java 工程位于 `EvaDance/`，包名 `cn.com.swod.app`，版本 1.0.0 (5)，最低 Android 8.0。使用 AGP 8.13.2、Gradle 8.13、JDK 17、compile/target SDK 36。

沿用小程序五栏：线上学院、线下课、赛事、商城、个人中心。本轮补齐品牌卡片、封面、商品分类/规格/价格、商城订单详情与操作、个人资料同步、学习统计、笔记/书签位置跳转，以及官网东方舞圈和品牌服务入口。线下采用购买期次课时、到课核销规则。工作人员和会员凭证分离，会员会话使用 Android Keystore 加密保存。

已完成真实 Android SDK 构建、6 项 Java 单元测试、35 项后端测试和 Release lint（0 错误、15 警告）。签名 APK/AAB 已生成，APK证书与备案材料匹配，App 专用后端已部署。Android 16 模拟器核验五栏、课程目录、登录保护、商城和返回导航通过；真实手机、SIM、视频及备案/市场验收仍缺证据。详见 [全自动完成记录](开发记录/20261014/全自动完成记录.md)。
