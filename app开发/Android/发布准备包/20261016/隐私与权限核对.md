# 安卓隐私与权限核对

核对日期：2026-10-16。适用安装包见 evidence/build-validation.json。当前为发布准备材料，尚未完成市场隐私审核。

| 项目 | 当前事实 | 提交前工作 |
| --- | --- | --- |
| 权限 | 实际 Manifest 仅 INTERNET，无电话、短信读取、通讯录、定位、相机、麦克风及全盘存储权限 | 各市场按最终 APK 的权限清单填报 |
| 短信登录 | 用户勾选协议后主动请求验证码，手工输入验证码；无自动读取短信 | 真机验证真实 SIM、限流、错误验证码及登录退出 |
| 文件 | 赛事音乐通过系统 ACTION_OPEN_DOCUMENT 主动选择，读取所选文件并上传；单文件上限 10MB | 政策明确文件名、音乐内容、参赛资料用途；测试取消选择和异常文件 |
| 会话 | App 访问凭证与刷新凭证在应用私有存储中以 Android Keystore AES/GCM 加密；后端保存会话及设备名称 | 说明会话、登录设备、安全日志处理及必要保存期限 |
| 资料 | 姓名、性别、生日、地区和地址为用户填写字段；收货资料包含收件人、手机和地址 | 政策逐项说明使用场景和可选性 |
| 学习 | 授权、进度、学习笔记、书签、证书；服务端按用户隔离 | 说明学习服务用途、查询删除和保存规则 |
| 赛事 | 姓名、手机、机构、老师、节目名、备注和参赛音乐；按实际公布规则展示成绩 | 核对公开展示范围及告知；不扩大成绩公开范围 |
| 订单 | 查询已有订单、物流、售后；尚未开放原生新购买/支付 | 不将支付 SDK 或不存在的支付流程写为已集成 |
| SDK | 当前 Gradle 无生产第三方库依赖，JUnit 仅测试；源码未集成号码认证、微信、广告、推送或统计 SDK | 服务端云服务/短信/视频供应商仍须逐项核对，不能据此宣称没有第三方处理者 |
| 网络 | API admin.swod.com.cn、官网 www.swod.com.cn；封面/视频地址可由后台返回 | 按最终真实资源域名和服务商补齐后台域名/处理者，不能只报两个静态域名 |
| 注销 | 应用内“个人中心→注销账号”发验证码并提交申请，申请后所有 App 会话退出；并非即时完成数据删除 | 明确运营处理时限、联系方式、记录保留及申诉路径；用专用测试账号验收 |
| 启动/同意 | 冷启动直接请求公开课程；协议勾选位于登录页，没有首次启动说明面板 | 检查首启、拒绝、后台网络及服务端日志的实际行为，再按市场要求决定整改，不能把登录勾选当完整隐私验收 |

现有官网隐私页面为 2026-07-25 的网站通用说明，2026-10-16 返回 HTTP 200。它没有完整说明上述 Android 会话、文件选择、收货资料、第三方处理者及具体保存规则。可用链接不代表内容已满足安卓上架要求。

建议补充的政策章节（草稿，尚未公开）：运营主体与联系方式；功能对应的数据类型/用途/收集时机；权限与文件选择；本地安全存储；服务商及第三方共享清单；保存地点/期限与到期处理；注销处理流程；未成年人规则；政策变更和联系渠道。具体承诺须与实际运营和服务器行为一致。
