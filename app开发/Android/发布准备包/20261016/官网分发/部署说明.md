# 官网 APK 分发准备

当前只生成本地资料，未新增官网按钮、未上传公开 APK、未部署或启用下载。release.json 为人工部署核对清单，不是已接入的在线更新接口。

待备案、命名、隐私与真机验收完成后：

1. 从本包 installers 选择精确 APK，核验 release.json 中的 SHA-256。AAB 不作为手机直接下载安装文件。
2. 将该 APK 放到版本化 HTTPS 路径（建议 /downloads/android/SWOD-1.0.0-5.apk）。这个路径是部署建议，尚不存在可确认的下载地址。
3. 设置 Content-Type: application/vnd.android.package-archive、Content-Disposition: attachment；支持 Content-Length 和 Range/续传。版本化文件可长缓存；下载入口/版本清单须及时更新。
4. 下载页展示真实应用名称、Android 8.0+、版本、大小、更新日志、App备案号、隐私政策、服务条款、客服和市场链接。备案号和市场链接必须填写真实已核验值，不使用占位号或提前显示“已上架”。
5. 用普通安卓手机在浏览器下载并安装，同步校验远端文件哈希、包名、证书、版本和更新覆盖。微信内浏览器按实际下载行为说明“在浏览器打开”，不伪造分发渠道。
6. 保存线上 URL、响应头、远端哈希与安装证据后，才把 release.json 改为 published 并记录 App 备案号。后续候选包要提高 versionCode；本轮保留既有未发布 1.0.0 (5)。

保留旧 APK 和回退说明；不要以未通过最终验收的候选包启用正式下载。
