# 本次 APK 真机验收

必须对 installers 中的 APK 验收，并记录 SHA-256、设备型号、Android 版本、测试日期和证据路径。模拟器记录只证明模拟器运行。当前 adb 仅发现模拟器，没有连接物理手机。

- [ ] 安装、升级覆盖、首次启动、拒绝/同意隐私、游客浏览、返回与重启。
- [ ] 自有 SIM 的短信验证码登录，验证码错误/过期、频率限制、退出、重新登录与账号切换。
- [ ] 有权限课程可播、无权限课程被拒绝；长视频播放、后台/前台、暂停、镜像、循环、倍速。
- [ ] Wi-Fi / 移动网络切换、断网恢复；进度同步、冲突处理、学习笔记和书签定位。
- [ ] 个人资料、已有商城订单、线下期次过滤、剩余课时与核销记录只读比对。
- [ ] “我的比赛”归属正确；已发布的 0 分可见，未发布成绩隐藏；报名/音乐选择先取消验收。
- [ ] 登录设备列表与撤销；注销说明与申请流程用明确授权的可销毁测试账号核验。
- [ ] 隐私政策、协议和支持页在真实手机可读，记录权限弹窗与后台行为。

涉及短信、修改资料、报名、订单操作、注销等写入，须使用持有人指定的受控测试账号；不得以真实会员或订单凑验收记录。

结果填写上线准备/manual-acceptance.json，沿用 manual-acceptance.example.json 字段并附证据。未测项目保留 false。每次替换 APK 后应按新哈希复核。
