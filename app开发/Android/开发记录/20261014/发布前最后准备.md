## 本轮收尾

- 登录：完整校验 App token/refreshToken；短信六位验证码、协议勾选、重复提交保护和一分钟验证码发送间隔。
- 会话：账号切换或退出后，拒绝此前认证请求及音乐上传的迟到响应，避免旧账号记录回到当前页面；拒绝损坏或旧格式的本地登录凭证。
- 注销：验证码只能发给当前账号手机号；申请明确说明所有 App 设备退出，保留服务端验证和待处理状态。
- 播放器：后台准备完成不自动播放；返回前台保留用户手动暂停状态；播放完毕同步进度；销毁后不更新界面；补齐 Android 8–10 的安全区；保留进度版本冲突控制。
- 导航和品牌：接入 Android 13+ 返回手势及已有品牌的各密度/自适应启动图标。
- 签名：沿用既有 PKCS12，公钥证书 MD5 和 SHA-256 均与备案材料一致。私有配置在用户 .config/eva-app 下，工程和源码包不保存私钥或口令。Release 缺少签名配置时停止构建。
- 仓库保护：忽略 .gradle、local.properties、signing.local.properties 和私有密钥库；未清理或覆盖其他任务变更。
- 赛事测试：夹具接入真实 ensureEventOnline/ensurePhoneMember，并补齐人员状态和评委表。此前 3 项失败已通过，新增代他人报名时参赛人员与实际提交人归属检查。

## 使用已准备的脚本

工程脚本目录：app开发/Android/EvaDance/scripts。

1. `accept-sdk-and-install.command`：持有人交互阅读并接受 Google SDK 许可，然后安装 API 36、Build Tools 36.0.0、Platform Tools。未接受时不会继续安装。
2. `build-release.sh`：设置 JDK 17 的 JAVA_HOME 后执行；依次运行单元测试、Release lint、Debug APK、签名 Release APK 和 AAB，并验证 APK 签名。
3. `release_preflight.py --output <检查.json>`：只读检查线上 App 接口、未授权访问、SDK、签名 APK 和真机/备案材料。未满足时返回非零并保留 NOT_READY。
4. `prepare_release.py --output <发布包目录>`：生成源码准备 ZIP、SHA-256 清单和测试证据；排除私钥、口令、SDK、数据库和本地环境。当前准备包不是可分发安装包。

最终构建仍需 apksigner 对 APK 证书和备案材料作实际比对；目前只证明既有私有密钥库对应证书匹配。

## 剩余发布阻断项

- SDK 许可尚待持有人确认，因此 API 36 和构建工具未安装，APK/AAB、Android lint/资源合并尚未完成。
- App 专用后端未上线。应在对照线上基线的隔离候选工程中编译和测试 App API、路由白名单、会话 schema、mini 业务依赖和中间件，不能把工作区其他未验收修改整体覆盖到生产。
- 原生 UI、真实安卓设备上的登录、权限、播放、进度、资料、订单、报名、注销和隐私流程没有验收证据。
- 备案及应用市场材料没有重新核验；本轮未提交备案或上架。
- 购物袋/购买支付、微信与号码认证 SDK、离线播放、统一 commerce 新订单中心等功能仍有缺口，未实现的小程序功能不能写成 App 已具备。官网品牌和资讯目前打开浏览器。

`上线准备/manual-acceptance.example.json` 提供待填写的验收字段。正式记录必须填入已测 APK 的 SHA-256，并附测试依据；示例全部 false 不能通过发布检查。

生产操作边界：本轮所有线上核验均为 GET，不产生真实会员、订单、退款、报名、短信或资料修改记录。
