## 放置规则

每个平台各自保存源码和发布资料，不把平台证书混放。跨平台架构、接口说明和备案公共资料放入共享资料。服务器 API 仍维护在 `../10-统一平台admin-platform/`，网站与小程序仍保留各自工程，避免复制出多份业务主源。

Apple 历史注册记录已归入 iOS；其中 9 月 13 日的页面状态不是当前账号核验结果。2026-10-02 本轮仅读取本地资料，没有登录开发者平台、付款、上传或提交审核。

私钥、密码、验证码及签名密钥库不得放入源码或普通资料目录。原签名私钥受控位置保持不动。本目录含注册资料与证书截图，不应整体公开发布。

整理清单：[20261002-文件归档清单.json](共享资料/整理记录/20261002-文件归档清单.json)。原路径 `app开发/ICP备案资料_20261002/` 下的资料按平台拆分；历史文档中的旧路径以该清单映射为准。
