按用户两张小程序截图参考布局，保留 App 酒红、白、浅灰和深色模式。此记录仅代表本地开发与下列检查，没有商店上传、提审或发布，也没有变更备案、包名或签名资产。

- 视频下方紧接当前课节标题、所属单元及学习进度。
- 目录、笔记、简介三个切换区，目录默认展开。播放速度、清晰度、镜像、循环等原功能收进播放设置；Android 和 HarmonyOS 继续使用原生视频控制器，iOS 保留原有长按倍速与进度保存。
- 搜索课节名称及单元；每页 50 节，显示当前范围和总页数。搜索重置第一页，切课定位当前课节所在页。原课节序号不会因搜索重排。
- 课节行包含序号圆圈、自动换行的标题、时长和右侧进度；当前课节用浅酒红底色标出。未知进度显示待同步。
- iOS 播放页收起底部主导航；返回栏使用实色背景，避免滚动内容和灵动岛区域重叠。序号圆圈随辅助大字体增大。
- 课程介绍来自原课程详情接口。笔记保留当前播放时间保存入口。
- 播放鉴权、进度冲突保护、已解锁课程权益规则沿用原服务端逻辑；目录元数据不授予播放权限。
