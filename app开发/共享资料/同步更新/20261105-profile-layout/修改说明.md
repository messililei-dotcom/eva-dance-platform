# 个人中心图文布局同步

以当前小程序 `pages/profile/profile.wxml` 为布局依据，同步 iOS、Android、HarmonyOS，保留酒红、白与浅灰主题，采用连续页面与细分隔线。

- 顶部显示头像、姓名、脱敏手机号及通知入口；安卓通知数字随未读轮询刷新。
- 线上课、线下课、我的比赛、我的证书组成四个图文入口。服务端未返回的统计不伪造为0。
- 资料、比赛、订单及下方学习/账号/客服服务使用图标、标题、说明和箭头。
- 我的课程带主图、绿色“✓ 已解锁”和“继续学习”。点击仍直接进入课程学习。授权接口只有编号/名称时，从公开目录按后台series ID补齐主图；公开元数据不参与权益判定。图片失败保留占位及学习入口。
- iOS辅助字号切换两列；安卓小屏/大字号切换两列；鸿蒙使用自动换行、自然高度的快捷入口。隐私、退出确认和未登录直达登录保持原行为。

三端本地编译通过；安卓32项单元测试与Debug lint通过；鸿蒙44项测试通过；iOS21项基础合同检查通过。日志和源码SHA-256在verification.json及evidence目录。

原生组件预览由SwiftUI ImageRenderer离屏渲染，使用本地虚构数据及实际组件，不是真机截图，不作商店素材。检查了普通、320pt窄屏与辅助字号布局分支。模拟器GUI入口缺失；未完成iPhone端字体/深色模式运行、真实头像与课程图片网络加载或真机验收。鸿蒙个人资料入口为原生只读资料页，资料编辑能力未在本轮新增。
