## 代码实现

- 三端新增“课程缓存”列表，播放设置提供缓存当前课节、暂停、重新缓存、删除和离线播放入口。重新缓存会重新申请授权并重新下载，不宣称断点续传。
- 下载只走官方SDK VidAuth安全下载；离线仅SDK本地URL源解密，没有普通URL下载回退或系统播放器明文回退。
- 服务端按已验证会话和后台series ID复核有效权益，绑定账号、会话、设备、课节和素材版本；有效期不超过24小时、权益期限及会话有效期。续期不再返回下载凭证。
- 有网时前台定时自动续期；无需用户手动续期。无网/服务故障保留当前有效授权，到期暂停播放；明确撤权或账号变化清理缓存。
- 时间以受保护的服务端锚点与含休眠的单调时钟推算；系统时间回拨不能延长授权，设备重启后必须联网自动确认。
- iOS索引/会话使用ThisDeviceOnly钥匙串；Android使用AndroidKeyStore AES-GCM；Harmony使用HUKS AES-GCM。媒体位于应用私有目录；iOS排除备份，Android禁用备份。
- 限一项并发、最多12节、总量2GB、每节不超过服务端1GB上限，并预留100MB空间。容量校验覆盖目录分片。
- 离线进度本地保存，联网按revision补传；发生版本冲突采用云端最新进度，避免覆盖其他设备的新记录。
- 水印及录屏/后台暂停保护已经接入；不承诺能防止外部拍摄、已越狱/Root设备或所有系统截图。Harmony隐私窗口及HUKS必须真机确认。
- 修复Harmony会话安全写入与取消/退出竞争，避免已取消的登录在重启后恢复。缓存管理器为进程共享实例，避免页面重建重复定时器。
