# 三端整体紧凑布局更新

按用户要求去除原生页面顶部重复标题，整体内容上移，保留原有品牌配色及内容中的必要名称、分组和表单说明。

- iOS：统一原生页面导航样式，导航标题为空；五个主入口隐藏独立导航栏，详情/表单保留返回和操作。内容区继续显示课程名、赛事名等必要信息。
- 搜索框统一为紧凑的内容内控件，至少 44 点触控高度，支持清空、搜索键收起键盘；首页搜索前移到快捷入口之前，赛事搜索与服务按钮并排放在概览之前，商城/线下课搜索位于内容顶部。
- 降低内容顶部间距和列表额外留白；iOS 17 及以上使用系统 contentMargins 调整列表，较低系统保持兼容。没有改变最低 iOS 16 要求。
- 灵动岛两侧继续由系统显示时间与信号，未将按钮或文字塞入系统状态区域。保留原生安全区，横屏不侵入侧边摄像区域；Android 同时计算 displayCutout 和系统栏/键盘 inset。
- Android、HarmonyOS 根页面隐藏重复标题栏；子页面保留返回/刷新操作，赛事服务移到搜索行，搜索与内容间距同步收紧。根页面可通过重新选择底部入口刷新数据。

验证：
- iOS 模拟器 Debug 及含 SDK 的未签名 iPhoneOS Release 编译通过；已检查五个主入口、详情返回、课程搜索/清空/收起键盘、横屏安全区及大字体；恢复 large 字号和竖屏。
- Android Debug、签名 APK/AAB、lintRelease 和 21 项单测通过；最新版 APK 已安装模拟器并启动。各页运行验收尚未完成，控制工具无法绑定其原生窗口。
- HarmonyOS 正式 HAP/APP 构建及原证书、原描述文件校验通过；模拟器不可用，页面运行验收尚未完成。
- 本次为布局调整，未新增只重复实现的测试；未改变认证、学习权益、商品价格、报名或支付逻辑。

iOS/evidence 保存首页、线下课、商城、个人中心、赛事、大字体和横屏截图；安装包位于各平台 installers；摘要与检查边界见 verification.json。
source-before 和 compact-layout.patch 保留本次针对当前工作区的变更。未修改备案、未部署后台、未上传或提审发布。
