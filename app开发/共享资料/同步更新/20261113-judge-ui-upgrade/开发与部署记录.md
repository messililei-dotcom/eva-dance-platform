# 评委与评分界面升级

官网手机版、桌面响应式与 PWA 已部署。iOS、Android、HarmonyOS 与微信小程序已更新本地源码；三端调试编译和小程序赛事模板编译通过。本次未上传、未提审，也没有创建商店发布候选。

## 功能

- 每个评分项支持数值输入与左右拖动，双向同步并实时更新合计。
- 合计得分可输入修改，按当前分项得分比例分配；全零时按各项满分权重分配；达到分项上限后分配剩余项目，使用百分位尾差补齐，保持合计一致。规则满分仍由服务端提供，总分维持10分制。
- 评委工作台展示本人评分进度和全部／未评分／已评分筛选。沿用本人获授权组别、锁定只读、修改评分和提交确认，官网补充退出登录后清理评分界面。
- 评委列表与详情使用真实后台公开资料及头像。官网以可展开资料展示详情，小程序新增详情页，原生端提供详情界面；未公开时不展示公开评委目录。
- 成绩榜单、头像、前三名荣誉榜和个人评分详情沿用真实发布状态；不提前生成排名，不虚构计分规则、人物介绍或分数。
- PWA 新版缓存标记为 swod-pwa-v16-judge-scoring-20261113，评委评分页面和 API 均不走离线缓存。
