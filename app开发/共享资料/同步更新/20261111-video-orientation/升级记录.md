# 视频横竖屏升级交付记录

日期：2026-11-11。范围：官网/PWA、微信小程序、iOS、Android、HarmonyOS。

## 已完成

- 官网/PWA：增加横屏/竖屏选择，全屏中可更换方向；统一标准和 WebKit 全屏状态/退出；退出和卸载释放方向锁；不支持方向锁时提示旋转设备，不通过重建 video 模拟切换。保持镜面画面、独立控制栏和水印同层。窄屏操作栏允许换行。
- 小程序：保留 90°横屏/0°竖屏全屏；补失败与超时恢复、后台退出及延迟全屏回调清理，不改变播放源与进度。全屏中使用微信原生退出入口，退出后可选择另一方向。
- iOS：在线、离线播放器增加横屏全屏、竖屏全屏、退出全屏；在线播放器在同一视图位置保留播放器；通过窗口场景 geometry 请求方向，退出恢复进入前方向；方向请求被拒绝时提示旋转设备。全屏隐藏导航和页面内容，保留安全区及播放操作。
- Android：增加全屏方向菜单和画面内入口，支持横屏、竖屏、退出及返回键退出；处理 configurationChanges 保留 VideoView；退出恢复原方向策略；适配刘海安全区及系统栏。
- 鸿蒙：增加横屏/竖屏原生全屏菜单、全屏事件同步和返回/后台退出。使用 SDK VideoController.requestFullscreen 的方向参数，保持播放源不变。原生全屏使用系统控制栏，实际镜面、水印和设备返回行为仍需真机验收。
- 更新官网过时的播放器测试目标至 video-client.tsx，并对照当前自定义控制层、倍速及连播实现修正断言；增加全屏 API 行为测试。未新增或修改课程授权、交易、价格逻辑。
