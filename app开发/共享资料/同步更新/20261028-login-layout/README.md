# 三端登录页同步更新

本次同步 iOS、Android、HarmonyOS。统一采用已确认的小程序登录布局，保留各平台原有酒红、白色和浅灰主题，不使用参考图的金红背景和绿色按钮。

| 平台 | 开发版本 | 编译与检查 | 安装或界面 |
| --- | --- | --- | --- |
| iOS | 1.0.0 (8) | 模拟器与含 SDK 的 iPhoneOS 未签名编译通过 | 同一会话已验登录布局、输入/协议、密码切换、深浅色和大字体 |
| Android | 1.0.0 (9) | Debug、正式 APK/AAB、lintRelease 及 17 项单测通过；沿用原签名 | 已安装模拟器并正常启动；当前控制工具无法绑定模拟器窗口，登录页运行验收未完成 |
| HarmonyOS | 1.0.0 (8) | 正式 HAP/APP 构建及原证书、原描述文件校验通过；27 项单测通过 | 模拟器未启动，hdc 无目标，界面运行验收未完成 |

布局：居中品牌区；一键登录、验证码登录同卡片；密码登录为备用入口；保留协议确认和返回。
Android、鸿蒙补齐按手机号计算的 60 秒短信冷却与状态提示。鸿蒙的延迟登录响应在账号切换或离开登录页后不再提交会话，新增 6 项异步回归用例。此次未发送真实短信或提交真实会员登录。

安装包位于 Android/installers 和 HarmonyOS/installers，摘要见 verification.json。AAB 的 jarsigner 报告 jar verified，同时有自签名证书链、时间戳与读取顺序警告，日志已保留；未进行商店接收验证。iOS 本次复用已验证的开发预览；没有生成或上传新的 IPA。

正式服务的一键登录仍未启用，三端均需带 SIM 卡真机验收。微信移动应用登录仍依赖原生配置和回调完成。
本次未部署服务器、未变更备案、未改商店资料，未提审或发布。构建、签名、安装、真机验收和上架分别记录，不等同完成。

source-before 和 native-update.patch 仅包含本次目标源文件的备份与定向改动，不含私钥、SDK Secret 或服务端凭证。
