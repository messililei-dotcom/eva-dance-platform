# 课程卡片放大主图

普通字号课程卡片的主图区域与右侧信息区域各占约一半宽度，保留原图比例完整显示。三端共同调整线上与线下课程卡片。

iOS 使用等宽布局，图片随卡片宽度增长，行高适应文字；标题最多三行，简介最多两行，保留教师、课时、价格或已解锁状态。辅助大字体切换为上下布局以完整阅读。
Android 图片与文字使用等权宽度，图片高度随实际宽度计算，缺图保留稳定占位。
HarmonyOS 主图和文字各占一份弹性宽度，同步收敛课程标题与简介行数；其他业务记录卡片保持原显示。

iOS 模拟器和含 SDK 的未签名设备 Release 编译通过，已查看普通字号与辅助大字体。Android Debug、正式 APK/AAB、lintRelease、21 项单测和原签名校验通过，已安装模拟器；课程页面运行验收未完成。HarmonyOS 正式 HAP/APP 构建与原签名验证通过，模拟器不可用，界面尚未运行验收。

仅调整展示布局，没有修改服务端课程权益、价格、支付、课程 ID 映射或鉴权。原图未裁剪替换。未改备案、未部署后台、未上传提审发布。
