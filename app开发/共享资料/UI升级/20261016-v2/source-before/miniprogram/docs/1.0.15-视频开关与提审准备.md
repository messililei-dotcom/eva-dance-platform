# 1.0.15 视频开关与提审准备

日期：2026-09-17。AppID：wxc2878927a69379ef。

## 当前行为

- 小程序课程仍可浏览；关闭视频时，课程卡片进入图文详情，隐藏播放按钮、播放器与练习续播区域。
- 统一后台「小程序管理 → 小程序应用 → 小程序视频播放」控制开关。没有配置时默认关闭；小程序取配置失败也关闭，不缓存曾经开启的结果。
- 每次页面重新显示和点击播放入口都会重新读取开关。旧分享链接、直接打开播放器，以及播放地址和签名流接口，均受开关控制。
- 开关对全部小程序用户采用相同行为。后续开启仍保留原课程授权校验；是否需要重新提审应以平台对视频服务、类目及功能变化的要求为准。
- 已经签发的云视频地址和已下载片段不能靠这个开关撤回；关闭后不再签发新的地址，用户返回小程序页面时停止旧播放器。

## 2026-09-17 渠道范围修正

仅 `x-client-platform: miniprogram` 标识的小程序播放请求受此开关控制。官网、PWA、App 和旧网页代理复用接口时继续执行各自原有登录、课程授权与播放逻辑，不读取小程序开关。视频流令牌签名保存渠道，防止浏览器/原生播放器请求不带自定义请求头时丢失渠道；历史无渠道令牌按网页处理，保持旧链接兼容。

无需重新上传小程序：1.0.16 已发送该小程序渠道标记，界面隐藏与关闭逻辑保持不变。
