# 伊娃东方舞小程序

这是微信小程序独立工程目录，可直接用微信开发者工具打开本文件夹。

## 目录

- `app.json` / `app.js` / `app.wxss`: 小程序入口配置与全局样式
- `pages/`: 小程序页面
- `utils/`: 接口请求封装
- `shared/`: 小程序与网页预览共用运行配置
- `preview/`: 网页预览版本
- `docs/`: 发布与操作文档
- `admin-related/`: 原网课后台中与小程序配置、模拟器相关的页面备份

## 检查

```bash
node scripts/check-miniprogram-consistency.js
```
