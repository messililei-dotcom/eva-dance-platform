# SWOD 第二轮界面升级：以小程序内容和规则校准

方向：简洁、明亮，突出课程与内容。范围为小程序、iOS、Android、HarmonyOS 源码；未提交审核、未发布，也未部署生产服务。

| 内容 | 小程序依据 | 本轮调整 |
|---|---|---|
| 线上学院 | 已发布课程、真实 ID、教师/分类、课节数、人气；播放受后台开关控制 | 小程序将大轮播改为横向课程列表，增加我的课程/课时与核销/报名与成绩入口；Android、鸿蒙补充课节信息。保持现有分享、搜索、课程详情和播放开关链路 |
| 线下课 | 课程期次购买课时，工作人员到课核销；余额、已核销与记录保留；无需预约 | iOS 移除账户、目录、付款说明中的预约/签到旧文案；Android、鸿蒙的课程详情进入余额页时携带真实 source_id。保留 iOS 原有 course_ids 过滤 |
| 赛事 | 开放状态与报名时间共同决定可报名；成绩按服务端发布状态展示 | 小程序列表、详情和提交前共用 event-state；未开放、未开始、已截止、已结束、已取消分别表达。服务端继续负责最终审核、名额、金额与权限 |
| 个人中心 | 已授权线上课、已购线下期次、比赛、证书、订单、通知和身份绑定 | 小程序保留原有数据与操作，统一明亮排版，修正订单说明；鸿蒙增加已存在 API 的课时核销和比赛记录入口 |
| 商城 | 真实商品、库存、购物袋；收货地址、支付、订单规则由原有链路负责 | 小程序统一商品页、结算与订单共用表面、按钮和字号；保留原有配送、金额核算、订单及支付限制 |
| 失败与恢复 | 网络失败不等于没有内容 | 小程序线上学院、赛事增加独立错误状态及重试；重新加载刷新正在搜索的计数 |

## 验证边界

- 小程序：微信开发者工具真实渲染截图，使用当前公开内容及已登录账号的只读内容；个人中心截图对姓名、头像、手机号做运行时脱敏，没有修改账号资料或本地登录凭据。
- 小程序异常状态图：通过自动化临时设置页面错误/空搜索状态；实际失败分支另有 VM 回归测试。没有伪装成真实网络故障。
- iOS：本地隔离测试数据；截图构建只在临时目录加入选项卡选择参数，产品源码没有自动化入口。
- Android：截图使用独立 cn.com.swod.app.uiqa 安装身份、公开 GET 内容；候选安装包来自加入截图参数之前的准确产品源码并单独验签。
- 鸿蒙：本轮源码同步，环境缺少 DevEco Studio，无法编译与设备截图；报告不提供冒充设备截图的设计图。
- 本轮未触发短信、报名提交、付款、下单、退款、核销或生产数据写入。认证刷新等原有只读会话机制不视为业务写入。
- 对齐的是本轮涉及的内容、入口与规则表达，不代表各原生端已具备小程序全部业务能力；支付与平台能力继续按各端已有开放状态处理。
