## 共用验收范围

线上学院、课节目录、授权播放、学习进度、笔记收藏；线下课预约签到；赛事报名；商城商品与订单；消息、证书、账号注销及设备撤销。三端均以小程序当前业务为基准，数据主源保持数字化平台。收费/退款、安全离线、微信登录与审核状态分别验收，不能用公开接口通畅代替。

## 准备顺序

1. 补齐 Android Studio、DevEco Studio 及SDK；安装时如出现需接受的新软件协议，按实际协议确认后继续。
2. 创建两端原生工程并采用已登记包名及签名，接入相同接口契约。
3. 部署前完成 App API 与现有支付改动的联合检查；当前没有部署生产或修改线上数据库。
4. Apple资格完成、微信移动应用通过及运营商通道生效后进行相应真机验收。
5. 应用备案遵循三平台材料齐备后统一提交的既定安排，不单独提交不完整备案。
