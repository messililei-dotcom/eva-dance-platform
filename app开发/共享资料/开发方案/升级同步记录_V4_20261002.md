# App 升级同步 V4：源码基线与发布差距

日期：2026-10-02。主工程基线提交 `af93b2d`，有多项网站/后台/小程序未提交改动。本轮没有覆盖这些改动、修改线上数据库或部署生产。

## 与 V3 的关系

保留 V2/V3 原稿。本轮此前没有客户端源码，已创建原生 SwiftUI + AVKit iOS 工程；V3 的 Capacitor 是建议路线，尚无可复用容器代码，先以原生实现课程学习和教学控制。Android/HarmonyOS 各自保留平台目录，接口契约和业务后端共用，不宣称 SwiftUI 界面可直接跨平台运行。

V3 的安全离线、短 Access Token/Refresh Token 轮换、设备撤销、独立学习事件与 `/api/app/v1` 仍未实现。当前使用既有 `/api/mini` 协议是开发过渡，不能把新增原生工程等同于完成 V3 全部 P0。

## 最近升级如何落到 iOS

| 近期模块 | 本地依据 | 本轮 iOS 落地/差距 |
| --- | --- | --- |
| 课程重命名、拖拽排序、目录与播放器统一 | mini/public/series/[id]/courses；后台在线课程组件；小程序 player | 保留服务端返回顺序；单课节使用已修改的单元标题，视频 ID 仍是 CourseVideo.id |
| 授权与账号联动 | member/authorized-series；recent-courses；_authorization | 读取已有账号课程；播放再次服务端鉴权，不用客户端自报 memberId |
| 进度完课不倒退 | video/[id]/progress 使用 MAX | 每 15 秒及离页/暂停后台时同步；沿用最远位置，尚非精确的跨端最近播放点；不自行重复发证或创建订单 |
| 消息中心升级 | member/messages；[id]/read | 游标分页、正文展示；已读使用 PATCH 与 recipientId，忽略消息中的外链行为 |
| 品牌证书模板和公开验证 | mini/certificates；certificate-brand | 显示既有证书与 `/certification?no=` 验证链接，不重复颁发、不复制模板主源 |
| 商城、实物支付与物流 | mini/shop；shop-core/payments/shipping；小程序 mall | 已纳入后续对接清单，首发学习版不展示交易入口；微信小程序支付不能直接移植 iOS |
| 线下课、赛事与个人资料 | mini/offline、events、member/profile | 继续使用统一后台，尚未在本轮原生界面实现 |

## 接口契约

| 用途 | 方法与路径（前缀 /api/mini） | 注意 |
| --- | --- | --- |
| 短信 | POST /send-code，phone | 真实环境发送有费用；本次没有请求 |
| 登录 | POST /student-login，phone/code | 现有服务会创建用户且来源固定 mini_program；上线前必须独立适配来源与注销 |
| 已授权课程 | GET /member/authorized-series | series_id 与 series_name |
| 最近学习 | GET /member/recent-courses | video_id 是播放 ID，不用 course_id 代替 |
| 目录 | GET /public/series/{id}/courses | 单元 id + videos[].id，保留顺序 |
| 播放 | GET /video/{lessonId}/play | authorized、play_url、quality_options；不落盘播放 URL |
| 进度 | GET/POST /video/{lessonId}/progress | 秒数 progress/duration，data:null 是合法空记录 |
| 消息 | GET /member/messages?cursor=&limit=20 | items/hasMore/nextCursor |
| 已读 | PATCH /member/messages/{recipientId}/read | 不是消息 id，不用 POST |
| 证书 | GET /certificates | camelCase DTO，验证链接仅接受自有 HTTPS 主机和已知路径 |

配置固定 `https://admin.swod.com.cn/api/mini`，令牌放 Keychain，本机不可迁移的解锁后访问。API 不自动跟随重定向，HTTP 明文媒体不接受。401 退出登录，403 停止播放，不无限重试或将令牌交给媒体主机。

## 本轮验证与限制

已建立 10 项可运行契约检查：课程/课节主键、HTTP 标识、空进度与畸形进度区分、401/403、顶层成功与业务拒绝、消息收件 ID 与分页、HTTPS/证书域名、有限进度值、数字支付与离线关闭。使用脱敏模拟样本，未进行真实学员登录或生产写入。

Xcode 项目/Info.plist/PrivacyInfo.xcprivacy 通过 plutil 语法检查。当前仅有 Command Line Tools；iOS SDK 编译、设备运行、签名与上传状态均为未验证。完整验收门槛见 iOS 注册与上架目录。
