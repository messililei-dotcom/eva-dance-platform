# iOS 登录页更新 · 2026-10-28

开发预览：1.0.0 (8)，模拟器隔离标识 cn.com.swod.app.parityqa。正式标识保持 cn.com.swod.app。
本次只更新本地 iOS 开发版并安装到模拟器；未上传、未提审、未发布此构建，未变更备案或苹果签名资产。

## 已完成
- 独立登录页：品牌区、分组输入、一键登录 / 短信验证 / 账号密码切换。
- 协议默认不勾选；有效手机号、六位验证码、显式同意、空闲状态共同决定提交。
- 验证码发送成功后按手机号计时 60 秒，避免重复发送；切换手机号清空旧验证码。
- 密码显示切换、忘记密码转短信、错误就地提示、尝试后和退出时清空密码。
- 阿里云运营商授权页品牌样式、保留运营商及隐私协议；仅有效取号令牌可送服务端换取会话，页面展示及勾选事件不能视为登录成功。
- 本机号码登录先检查服务配置；取消、超时和不支持设备保留短信入口。SDK 只在用户明确同意并发起后调用。
- 关闭登录时取消请求；账号变更或取消后的过期响应不能恢复旧登录。
- 页面切换导致的正常请求取消不再误弹 cancelled。
- 深浅色、较大辅助字体、协议换行；不支持一键登录时明确说明。
- 延续服务端学习权益校验及原有 Keychain 保存方式，无明文凭证降级。

## 验收
- 模拟器 Debug 构建成功（Xcode 本地临时签名）；iPhoneOS Release 含 SDK 未签名编译成功。
- EvaCoreChecks：原有 21 项契约检查及新增登录输入、同意、倒计时、运营商事件边界组，零失败。
- 本地 loopback fixture：短信倒计时、短信登录、密码错误提示及清除、密码登录成功，登录后我的课程显示“✓ 已解锁 / 继续学习”。
- 登录测试仅访问本地测试服务，不发送真实短信、不操作真实学员账号。
- 模拟器无法 SIM 认证时，一键登录按钮不可提交，短信备用入口有效。
- 检查大字体和深浅色显示，完成后恢复原来的 large / light。
- 最终模拟器退出 fixture 模式，连接正式公开服务，停在空白登录页供标注。

## 尚未开放的能力
当前正式 /config 的 oneTapLogin=false，本次没有启用正式开关。
一键登录需要匹配正式标识的签名安装包、启用服务及带 SIM 卡的 iPhone 实测；模拟器和未签名编译不能证明运营商认证成功。
微信原生登录及回调依然待完成，本次没有添加不可用的微信登录按钮。
实际发布包、备案签名核验、上传和商店状态属于后续发布流程。
