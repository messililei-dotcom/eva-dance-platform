## V3 工程整合与交付基线
2026 年 9 月 13 日　　适用平台 iOS iPadOS Android

本方案面向项目负责人、产品、研发、测试和运营团队，将现有官网、微信网页、小程序、统一后台和阿里云 VOD 接入正式移动学习客户端。首发交付已有学员的登录、已授权课程、稳定在线播放、安全离线缓存和跨端续学；数字课程购买作为后续独立版本评审。

| 数据实体 | 行数 | 业务含义 |

### 唯一业务映射
Member.id → CourseAuthorization.member_id；授权按 series_id 关联 CourseSeries。课程内容路径为 CourseSeries.id → OnlineCourse.series_id → CourseVideo.course_id → Material.id，其中 CourseVideo.material_id 指向素材，Material.vod_video_id 指向阿里云媒资。[L3 L4 L5]

APP 契约固定 seriesId＝CourseSeries.id、unitId＝OnlineCourse.id、lessonId＝CourseVideo.id、materialId＝Material.id、vodVideoId＝Material.vod_video_id。不得将 OnlineCourse.id 当作视频 ID，也不得将不同课节引用的同一素材合并为同一学习记录。分组沿用 group_id、group_name 和 sort_order，不另造不兼容章节主键。

### 生产核验与数据质量
阶段 0 使用同一时点的只读生产快照核验：有效主账号、已发布系列与单元、可播课节、去重 VOD 媒资、引用缺失、有效授权、过期授权、完整 VideoId 覆盖、媒体大小与加密状态。课程业务数量、素材数量和云存储字节数分别统计，禁止互相推算。

本地 WechatIdentity 为 0 行、CourseOrder 为 0 行，不能据此判断线上没有微信用户或没有成交。9 月 11 日授权列表实收金额记录与本地授权 schema 不一致，说明必须先完成源代码和数据库版本对齐，再决定增量迁移。[L3 L9]

### 首发学员路径
建议四个主入口为“学习首页、我的课程、下载、我的”。首页优先展示继续学习；我的课程展示系列有效期和最近课节；下载页展示可播、下载中、待续期及空间占用；个人页包含账号、设备、帮助、隐私、注销和版本信息。免费内容可单独展示，首发不复用含价格或授权申请销售引导的整块旧页面。

播放器必须有上一节、下一节、清晰度、倍速、镜面、循环与横屏控制。镜面是东方舞教学核心体验；9 月 9 日官网播放器已保留镜面、画中画和容器级全屏，APP 应复用交互意图，但需要原生重实现和真机验收。[L10]

### 优先级与范围控制
P0 为登录、权益、目录、在线播放、安全离线、续学、设备撤销、适老化、隐私注销、后台策略与故障恢复。P1 为笔记、书签、学习消息、成长和证书展示；若延期则隐藏入口。P2 为数字课程购买、分销、赛事报名、线下预约、电商、投屏扩展及纯鸿蒙客户端，另行评审。

正文建议默认 18 等效字号且可放大；主要操作区按 iOS 44 pt、Android 48 dp 的项目设计目标验收。错误必须给下一步操作，支持 200% 字号检查、读屏标签、大屏横竖屏和触控容错。以上为项目设计目标，不是当前页面已达标的结论。

# 四 客户端与服务端架构
### 推荐路线与决策条件
保留现有 Next.js 后台及业务库，在统一工程内规划独立移动客户端子目录，优先验证 React 业务界面加 Capacitor 容器；媒体、下载、许可校验与安全存储由 Swift/Kotlin 模块负责。新增目录为建议结构，不表示目前已有 APP 源码。

客户端打包本地 HTML、脚本、样式和离线目录视图，联网读取业务 API。服务端路由、数据库驱动、Node 依赖及密钥不能进入客户端。Next.js 服务端应用不能未经拆分直接当作静态 APP 资源；Capacitor 的 webDir 对应打包资源目录，server.url 不作为正式首发主界面方案。[W1]

### 技术样机先于完整界面
用同一组脱敏课节在 iPhone、iPad 和 Android 验证签名安装、授权播放、镜面与倍速、加密下载、断网冷启动、重启后续播、包升级后缓存读取。使用当前素材及拟转码样本，分别验证 MP4/HLS、加密类型、清晰度和音视频类型。

样机最长先安排 10 个工作日，输出复用清单、SDK 版本与许可、桥接接口、缺陷及录像。若本地页面难拆分、原生桥接不稳定或目标体验不达标，比较 Flutter 与原生实现的实测成本后重新决策，不能以“复用前端”掩盖不可维护的容器。

### 边界与桥接契约
业务页面只传 lessonId、quality 和播放意图；原生层通过受控会话获取媒体授权，返回播放器状态与下载任务事件。下载任务不能由网页层直接传任意 URL 或文件路径。桥接接口定义 schemaVersion、requestId、错误码及订阅释放行为；敏感令牌尽量留在原生层。

导航限制为自有可信来源，第三方页面在不暴露原生桥的外部浏览器中打开。WebView 执行内容和可调用桥接方法分别设白名单，测试脚本注入、跳转与深链参数；离线队列和缓存按账号隔离。

### 最小后台改造
在 src/lib/server 下抽取身份、权益、媒体授权和进度服务，在 src/app/api/app/v1 增加薄路由层；旧 /api/mini 路由通过适配器调用同一规则。客户端与 API 用版本化 DTO 共享类型，禁止直接共享数据库模块。首发继续用现有 SQLite，压测证明必要后再单独评估数据库迁移。

# 五 身份 权益与系统联动
### 账号与会话
当前学员令牌为 HMAC 签名的 payload.signature 格式，发放有效期为 3 天；现有读取路径通过 Bearer Token 解析学员 ID。它不是已经具备刷新轮换和设备撤销的 APP 会话体系。[L4]

新增 AppDevice 和 AppSession，Access Token 建议 15 分钟、Refresh Token 建议 30 天且轮换；具体参数由阶段 0 冻结。刷新令牌只存摘要，轮换在事务内完成，检测旧令牌重用并撤销同一令牌家族。并发刷新由客户端单飞处理；服务端明确重复请求与重用的区别。APP 新会话与旧端令牌并行兼容，不能要求已安装旧端立即升级。

沿用已验证手机号登录。归并账号须解析 merged_to_member_id 的最终主账号并检测循环，校验状态；新事件、权益与设备统一落到主账号。保留手机号国家区号字段，优先兼容已有中国手机号存储，再按独立迁移处理国际号码，不批量改写历史授权手机号。[L3 L6]

### 微信身份边界
WechatIdentity 按应用和 OpenID 记录身份，UnionID 用于具备可信来源的跨应用关联。APP 微信登录需新增移动应用身份渠道及对应开放平台配置，不能把小程序 OpenID 当作 APP OpenID。UnionID 缺失时使用手机号验证绑定；两个非空且冲突的 UnionID 进入人工核对，禁止静默合并。[L6]

### 权益统一判定
保留 getVideoAccessStatus 对系列、单元、视频发布状态、系列授权、免费和试听的规则。APP 在此之上补充主账号状态、设备、版本策略及动作类型。授权手机号兼容匹配只能使用服务端读取的已验证身份，不能接受客户端自报手机号或 memberId。[L5]

下载规则单独计算：canPlay 不意味着 canDownload；试听默认不可下载，免费系列是否下载由后台单独配置。撤权、到期、退款、冻结与设备解绑统一触发许可撤销事件。退款必须按具体订单及授权关系处理，有其他有效授权时重新求值，不一刀切撤销整个账号。

### 金额与成长不可重复入账
CourseAuthorization 的实际收款信息、Payment、CourseOrder 与 orders 之间已有统计去重规则。APP 埋点使用独立 platform/channel 字段，仅代表学习终端；不覆盖顾问、获客渠道、实收及支付时间。完课只触发一次成长事件，证书仍按原条件评估，不能仅凭客户端 complete 声明发证。[L9 L11]

# 六 API 契约与数据扩展
所有下列 /api/app/v1 路由均为拟新增接口。沿用旧接口响应不变，APP 统一使用 data、error.code、error.message、requestId 和 serverTime。身份从服务端会话取得，写接口按账号或会话作用域校验幂等键。
| APP 路径与方法 | 复用来源或新增能力 |
| POST /auth/login refresh logout | 复用手机号验证，新增设备会话与轮换；三个独立路由 |
| GET /me/courses | 适配 /api/mini/member/authorized-series，返回有效期与权限原因 |
| GET /series/{id}/lessons | 复用课程关联与排序，分页返回单元和视频课节 |
| POST /lessons/{id}/play-authorization | 复用权益判断，新增原生 SDK 播放凭证 |
| POST /lessons/{id}/download-authorization | 新增下载资格、许可与媒体版本 |
| POST /offline-licenses/renew | 批量续期，逐项返回有效或撤销状态 |
| POST /learning-events/batch | 新增幂等接收、拒收原因与聚合版本 |
| GET /learning-progress | 返回续播点、完成状态及版本游标 |
| GET /devices 与 DELETE /devices/{id} | 自有设备查询与撤销，服务端强制所有权校验 |
| GET /app-config | 版本、维护、离线策略；返回值不得含密钥 |
| POST /account-deletion-requests | 身份复核、撤销会话及后续删除流程 |

错误码至少包括 AUTH_EXPIRED、ACCOUNT_DISABLED、ENTITLEMENT_DENIED、DEVICE_REVOKED、MEDIA_NOT_READY、OFFLINE_NOT_ALLOWED、LICENSE_EXPIRED、CLOCK_UNTRUSTED、VERSION_UNSUPPORTED 和 RATE_LIMITED。401 允许刷新一次，403 不盲目重试，429 按 Retry-After 退避，5xx 有界重试；业务失败与网络离线区别展示。

### 旁路新增实体
AppDevice 记录 member_id、安装标识、设备公钥摘要、状态及最后活动；AppSession 记录设备、刷新摘要、家族、过期和撤销。OfflineLicense 记录课节、素材版本、授权来源、策略版本、签发与到期；DownloadAudit 只保存必要授权及结果，不保存可复用播放地址。

LearningEvent 对 event_id 建唯一索引，并约束 session_id 与 client_seq；LearningCheckpoint 对 member_id 与 lesson_id 唯一，含 resume_position、completed、revision 和权威会话。AppVersionPolicy 保存平台、渠道、最低版本和开关；AppOutbox 保存待处理撤销及成长事件。审计中记录操作人及变更前后值，敏感字段脱敏。

所有表名为建议，阶段 0 检查是否与线上实体冲突。UTC 时间字段与现有 localtime 字段通过明确转换边界对接，不全库直接改时间格式。外键策略、唯一约束、分页游标、最大批次和 schema 迁移号应进入 OpenAPI 与数据字典后再编码。

# 七 在线播放与媒体治理
### 当前链路与目标链路
当前 /api/mini/video/{id}/play 在校验课节权限后，调用 getVodPlayOptions 获取播放 URL 与清晰度；其 GetPlayInfo 默认 AuthTimeout 为 3600 秒。还保留音频、外部 URL 与本地受签名 stream 接口的兼容路径。这不是原生 PlayAuth 下载链路，也不能直接等同于永久公开地址。[L4 L7]

APP 授权接口只接受课节 ID 和清晰度意图。服务端解析素材及 VOD ID，判断权益、设备和媒体就绪状态，再签发短时 VidAuth 所需凭证或严格限权的临时 STS。优先验证 PlayAuth 方案，禁止把长期云访问密钥传到客户端；媒体流量走 VOD/CDN，应用服务器不承担全量视频中转。

### 媒体盘点与增量处理
素材中心继续维护目录、封面和引用，Material.vod_video_id 为媒资主标识。下载清单须包含素材版本和实际下载规格；同一个素材被多个课节引用时可复用文件，但授权和学习记录仍按各课节验证，文件删除使用引用计数。

阿里云安全下载有 SDK、鉴权方式、下载配置和媒体加密前提；必须核对当前媒资是否满足，不能承诺 1827 个 VOD ID 无需处理即可离线。必要时生成兼容的加密转码输出，先评估时间、费用及原有 Web/HLS 路径，保留旧端可用格式。完成样机前不批量转码、不迁移或重复上传全库视频。[W2]

### 原生播放器要求
播放失败按令牌过期、权益失效、转码中、素材缺失和网络故障区分。支持清晰度切换保留位置，倍速、镜面、循环、横屏和音频打断恢复；全屏仍能操作关键教学控件。音频课件单独标识可支持范围，非 VOD 资源未验证前仅在线可用。

投屏、AirPlay 和画中画必须与加密播放、水印及防录屏实测兼容；未达标时关闭相应入口。iOS 不能承诺普遍阻止截屏，Android 防截屏与 iOS 录屏检测分别实现。动态水印不展示完整手机号；安全目标是提高普通导出和共享门槛，不承诺阻止外部拍摄。

### 播放授权的失效边界
在线播放周期性检查权益与设备状态，建议最长 60 秒一次，失败需区分暂时断网与明确撤销。已签发媒体地址或已缓冲数据存在有效窗口，后端开关不能追溯消除。通过短凭证、心跳和客户端停播配合控制，测试并报告实际撤销延迟，不描述为即时绝对防盗。

# 八 安全离线与设备许可
### 文件加密和业务许可分开负责
阿里云安全下载用于加密本地媒体并约束指定 APP 的播放器使用；自有许可用于限制账号、设备、课节、有效期和素材版本。SDK 的 APP 绑定不能被视为已经完成个人账号或单设备绑定。[W2]

许可由服务端非对称签名，客户端内置公钥并支持 keyId 轮换；私钥留在服务端。字段至少为 licenseId、memberId、deviceId、deviceKeyHash、lessonId、materialVersion、quality、issuedAt、expiresAt、entitlementVersion、policyVersion 和 signature。原生层逐次验签，不允许网页层跳过许可直接调用本地播放器。

### 可执行的失效规则
默认建议离线 7 天，expiresAt 取课程授权到期、当前时刻加策略期限、设备许可期限的最小值；永久课程权益也只发短期离线许可。已到期、签名错误、账号不符、设备不符和素材版本失效均禁播。联网后批量核验，明确撤销时停止播放并清除对应可用授权。

完全断网无法立即获知退款或后台撤权，剩余可播窗口上限为已签发许可期限。联网撤销与断网自然到期必须分开验收。若业务要求立即撤权，相关课程不能提供完全离线播放，不能靠远程开关作出矛盾承诺。

### 时间 账号与缓存保护
使用可信服务端时间锚点加单调时钟估算时间；检测系统时间回拨。设备重启后若无法可靠恢复时间可信性，要求联网校验后继续播放，不承诺重启跨时钟场景永远无网可用。该限制需在样机阶段确定，并向学员清晰提示。

用户退出、切换账号或注销时撤销本机授权并隔离队列，禁止另一账号读取缓存；卸载重装或签名变更重新登记设备。缓存存放 APP 私有目录并排除不适当的系统备份，Keychain/Keystore 只存必要密钥材料或引用。设备私钥、媒体文件和签名许可复制到另一设备时必须无法正常使用。

### 下载状态与恢复
状态统一为排队、授权中、下载中、已暂停、校验中、可播放、待续期、已失效、损坏。写入临时文件，校验后原子变更为可播放；每个任务用账号、课节、素材版本和清晰度去重。默认 Wi-Fi 下载，并发建议 2 个；空间预留按实测媒体大小与 SDK 临时开销计算，支持失败退避和手动清理。

后台下载能力取决于系统和 SDK。分别记录退后台、锁屏、系统回收和用户强制结束进程后的结果；用户强杀后允许任务暂停、再次启动恢复，不能以“必须持续后台下载”作为所有平台的承诺。若 SDK 不支持保留分片恢复，必须明确重下成本并重新评审离线门禁。

# 九 学习进度与事件一致性
### 优先修复现有覆盖语义
当前 VideoProgress 写入使用本次 position 与客户端 duration 判断 90% 完成，并覆盖 completed；回看前段可使已完成记录退回未完成。内存 Map 的 10 秒节流不能代替多进程幂等与持久队列。将此项列为 APP 前置服务端修复，保留旧字段兼容。[L4]

新增聚合规则将 completed 视为单调状态，只有后台显式重置可回退。续播点允许向前回看，不能取历史最大位置。时长以服务端可信素材时长为准，未知时长不得仅靠客户端数据自动完成；位置达到 90% 与实际观看覆盖分别记录，证书沿用其自身判定规则。

### 事件接收与原子提交
事件包含 eventId、sessionId、clientSeq、lessonId、position、eventType、clientPlayedAt 和内容版本，账号及设备从会话得出。建议每批最多 100 条且限大小，逐项校验有限数值、课节归属、范围、会话与授权，返回 acceptedIds、rejectedItems 和 progressRevision。

eventId 唯一去重，sessionId 加 clientSeq 限制重复序列；事件、聚合和 Outbox 在同一数据库事务内提交，提交后才确认接收。返回成功但尚未落盘的事件不得从客户端删除。对于重试，已接收事件再次返回已接受；部分失败只重传可恢复项目，永久无效事件进入隔离队列。

### 跨设备乱序的确定规则
同一会话按 clientSeq 选择最新 checkpoint。跨设备以服务端签发的会话顺序确定权威会话，较旧会话的迟到事件可补观看统计和完成状态，但不能覆盖较新会话的续播点；不用客户端时间或批量上传到达时间简单决定输赢。

离线起播使用预发的离线会话标识，绑定最近服务端 progressRevision。同步时若 revision 已变更，则保留事件和完成度，续播点保留服务端较新位置；用户主动选择“从本机位置继续”时创建新的在线权威会话。界面要能解释两个设备不同位置，不静默丢弃全部学习记录。

### 旧端与成长联动
新聚合以旁路表验证，旧 VideoProgress 继续作为兼容读模型。旧写接口先经统一规则适配，并合成服务端事件 ID；没有事件 ID 的旧请求只能承诺快照幂等，不能保证精确观看时长。影子比对稳定后切到统一写入服务，再让旧端读兼容投影，禁止两套聚合互相反复回写。

完成事件以学员、课节和规则版本去重，再调用既有成长、消息和证书逻辑。离线记录到达时权益已过期但能验证学习发生在有效许可内，可接受历史学习统计；这不恢复当前播放权限。队列满时保留检查点、提示同步并暂停非必要高频采样，不能无限增长。

# 十 迁移 发布与运行保障
### SQLite 与生产数据约束
继续通过 ADMIN_DB_PATH 或 UNIFIED_DB_PATH 解析业务数据库。迁移使用独立 migration runner 和 SchemaMigration 记录，避免在高频 APP 请求中重复执行建表与改表。遵循 SQLite 单写者约束，事务内不等待 VOD 网络调用；小批次回填、设置忙等待并以压测确定批量大小。[L3 L4]

生产数据库禁止被本地文件、发布包或 rsync 覆盖；排除 *.db、*.db-* 及实际数据库、备份目录。备份使用数据库一致性备份流程，不能只复制正在 WAL 写入的主文件。恢复演练使用隔离副本，核验 integrity_check、行数及关键业务不变量。

### 增量发布顺序
1. 核对发布基线与生产只读 schema；保存代码版本、配置和一致性备份，脱敏副本演练。
2. 新增旁路表及索引，旧应用不依赖新表；验证锁时长和幂等重跑。
3. 部署兼容服务及默认关闭的 APP 功能，完成旧端登录、播放、授权、财务回归。
4. 内部账号验证原生包；20 至 50 名学员试用后按 5%、20%、50%、100% 开放服务端能力。
5. 每档至少观察 48 小时并覆盖一次完整学习及下载过程；样本不足继续观察。全量后保留旧 API 兼容窗口。

### 回退不能覆盖新增业务
优先关闭新下载授权或切回稳定服务端版本。已签发离线许可在离线期间仍可有效，关闭下载开关不等于召回缓存。旁路表保留并停止新写，避免急删表影响旧版本兼容；数据修正以增量补偿为主。

整库恢复仅用于重大数据灾难，需停止相关写入、确定恢复点并补齐恢复点之后的订单与授权，不能将旧备份覆盖当作常规回滚。已安装 APP 不能自动降级；通过兼容 API、功能开关和修复版本恢复，最低版本策略只在确有必要时启用。

### 运维目标与后台入口
在统一后台新增 APP 版本、设备、离线许可、故障查询和策略审计，沿用管理员权限体系。查看与撤销权限分开；重大批量撤销记录原因及影响范围。客服能按脱敏账号和 requestId 查询，不能查看刷新令牌或密钥。

建议 P0 立即响应、P1 15 分钟响应并在 2 小时内给出缓解措施。监控登录、授权、下载、同步积压、SQLite busy、首帧、卡顿、崩溃和退款撤销延迟。RPO 暂定 15 分钟、RTO 暂定 2 小时，属于待验证目标，须由备份频率与恢复演练证明后才纳入承诺。
