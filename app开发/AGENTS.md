# App 多平台同步规则

用户要求：各平台 App 保持同步更新。

- 修改通用界面或功能时，核对 iOS、Android、HarmonyOS 对应实现并一并同步；保留已有未提交改动，不覆盖其他任务成果。
- 登录页参考小程序的布局，保留各平台既有酒红、白色和浅灰主题及深色模式。使用真实运营商授权流程，不仿造微信号码授权窗口。
- 使用已有服务端身份与学习权益校验；一键登录、短信和密码入口均保留明确协议确认、错误提示与备用路径。不得以客户端手机号或 SDK 页面事件代替服务端认证。
- 同步后运行各平台适当的编译和回归检查，在共享资料/同步更新内记录源码、构建、签名、安装、界面验收、真机与商店状态；未完成的检查明确列出。
- 沿用现有包名、Bundle ID、签名和备案。三端同步开发不代表已上传、提审或公开上架；商店操作与备案变更按用户的具体指令执行。
- 根目录课程权益展示规则继续适用。

- App 不提供后台、管理员或工作人员的管理入口、管理登录和管理 API 调用；后台操作仅在网页后台进行。赛事评委入口属于会员身份下的获授权评分流程，保留评委权限校验，不将其升级为后台管理。

- 课程视频正常播放时保持画面干净，不叠加学习码、笔记弹幕或常驻按钮；播放控件仅按用户操作显示，笔记在视频画面下方展示。不得因此移除播放鉴权、录屏保护或授权失效时的阻断。
