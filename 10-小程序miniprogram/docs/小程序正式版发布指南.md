## 🔧 小程序运行机制

### 会员识别方式

小程序采用**手机号授权**模式，无需微信登录：

1. **未授权学员**：可以浏览课程列表，点击课程时提示联系伊娃老师开通
2. **已授权学员**：管理员在后台按手机号授权后，学员输入手机号即可同步训练记录
3. **管理员**：在后台"小程序配置"中添加管理员手机号后，可在小程序内管理训练

### API 端点

| 端点 | 功能 | 说明 |
|------|------|------|
| `/public/series` | 获取课程列表 | 无需授权，公开访问 |
| `/public/series/:id` | 获取课程详情 | 无需授权 |
| `/authorization/check` | 检查授权状态 | 需要 member_id |
| `/member/authorized-series` | 获取已授权课程 | 需要 member_id |
| `/member/profile` | 获取会员信息 | 需要 member_id |
| `/admin/status` | 检查管理员状态 | 需要 member_id |
| `/video/:id/play` | 获取视频播放地址 | 已授权学员；优先 VOD，失败回退素材中心本地地址 |

1. **URL 校验**：`project.config.json` 和 `project.private.config.json` 中 `urlCheck` 为 `true`，生产环境会校验合法域名
2. **HTTPS**：API 地址必须使用 HTTPS（已配置）
3. **域名备案**：`admin.dongfangwuquan.com` 需完成 ICP 备案
