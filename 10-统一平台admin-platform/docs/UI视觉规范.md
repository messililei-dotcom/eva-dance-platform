# 统一平台 UI 视觉规范

## 1. 参考模板结论

本平台视觉方向不是通用企业后台，而是：

```text
东方舞品牌感
女性学习成长场景
轻奢、明亮、精致
深色侧栏 + 白色工作区
粉紫渐变主色
数据密集但不压迫
```

## 2. 后台视觉结构

后台固定结构：

```text
左侧深色品牌导航
顶部白色工具栏
中间浅灰白工作区
卡片式数据模块
表格密集管理区
粉色主按钮和选中态
紫色作为次级高亮
```

## 6. 新平台实现要求

```text
不得 iframe 旧页面
不得使用默认 Ant Design 味道
不得使用纯灰企业后台风格
不得做营销官网式大 Hero
后台页面必须信息密度高、可扫描、可操作
```
