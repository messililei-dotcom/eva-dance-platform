# 微信支付配置

收费支付中心 → 微信支付配置提供受总管理员权限保护的检查页。只显示脱敏商户号、AppID 和校验结果，不回传密钥、文件路径、环境值或底层错误。接口为 `GET /api/commerce/wechat-config`，使用现有收费中心 Bearer 鉴权及有效账户检查，禁止缓存。

## 服务器配置

参考 `.env.wechat-pay.example` 将变量加入服务的秘密环境配置；示例文件不会自动加载。真实配置不入库、不提交 Git、不放入浏览器或小程序。

| 变量 | 来源与要求 |
| --- | --- |
| WECHAT_PAY_MCH_ID | 商户平台的 10 位商户号 |
| WECHAT_PAY_APP_ID | 与商户号关联的 AppID，小程序支付应使用对应小程序 AppID |
| WECHAT_PAY_SERIAL_NO | 商户 API 证书序列号，十六进制；不是微信支付公钥 ID |
| WECHAT_PAY_NOTIFY_URL | 计划使用的公网 HTTPS 支付通知地址，不含查询参数、账号或片段 |
| WECHAT_PAY_PRIVATE_KEY_FILE | 商户 RSA 2048 私钥 PEM 文件的绝对路径 |
| WECHAT_PAY_API_V3_KEY_FILE | 保存 32 位数字/大小写字母 API v3 密钥的文件绝对路径 |
| WECHAT_PAY_PUBLIC_KEY_ID | 商户平台下载的微信支付公钥对应 ID，以 PUB_KEY_ID_ 开头 |
| WECHAT_PAY_PUBLIC_KEY_FILE | 微信支付 RSA 2048 公钥 PEM 文件的绝对路径 |

三个 `_FILE` 变量也可改用去掉 `_FILE` 后的环境变量传入内容；同一项只能选一种。PEM 环境值支持换行或字面量 `\n`。推荐将文件放在仓库及网站公开目录之外，私钥与 API v3 密钥文件权限设为 `600`，服务进程用户可读。文件最大 32 KiB。

更新环境后重启服务，再点击“重新检查”。`getWechatPayConfig()` 在校验失败时拒绝返回配置；校验通过时可供服务端 `WechatPayV3` 使用。公钥模式请求附带 `Wechatpay-Serial`，响应与通知仍按报文携带的 ID 选择公钥验签。当前配置读取器只提供单公钥模式，未实现平台证书下载或新旧公钥轮换。

## 检查边界

检查只校验格式、文件可读性与 RSA 密钥类型/长度。不会联网下单，不检查私钥是否匹配商户证书序列号、公钥是否属于对应 ID、AppID 绑定、商户签约权限或回调可达性。配置齐全仍保持在线支付关闭，现有人工收款流程不变。

此版本未新增支付通知路由，因此不能将任意填入的通知地址当作已上线接口。正式收款还需实现下单、到账通知幂等落账、履约、主动查单、关单、退款、对账以及小程序/官网调起流程，并完成商户联调和真实交易验收。不同渠道的 AppID 必须分别确认，不能自动沿用公众号登录 AppID。

官方参考：[开发必要参数说明](https://pay.wechatpay.cn/doc/v3/merchant/4013070756)、[配置 API v3 密钥](https://pay.wechatpay.cn/doc/v3/merchant/4012072195)。
