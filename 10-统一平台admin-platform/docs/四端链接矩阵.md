# 官网、后台、网课小程序链接矩阵

本文件用于统一梳理 `www.dongfangwuquan.com`、`admin.dongfangwuquan.com` 与网课小程序之间的入口关系。代码侧统一维护在：

```text
src/lib/platform-links.ts
```

页面、设置项、跨端按钮不得再各自硬编码域名。

`/learn` 与 `learn.dongfangwuquan.com` 已废弃并从统一平台删除。

## 一、三端定位

| 端 | 正式入口 | 定位 |
| --- | --- | --- |
| 品牌官网 | `https://www.dongfangwuquan.com` | 品牌展示、招生转化、课程与活动公开展示、电商公开展示 |
| 统一管理后台 | `https://admin.dongfangwuquan.com` | 管理员唯一入口，管理会员、课程、订单、电商、财务、小程序配置 |
| 网课小程序 | 微信小程序 | 移动端学习、课程购买、消息触达，与 `miniapi`/`auth` 通信 |

## 二、链接关系

| 链路 | 目标 | 用途 |
| --- | --- | --- |
| 官网 -> 统一后台 | `https://admin.dongfangwuquan.com/login` | 仅管理员入口，不作为普通用户路径 |
| 后台 -> 官网 | `https://www.dongfangwuquan.com` | 内容、课程、活动、商品发布后的官网预览 |
| 后台 -> 网课小程序 | `https://admin.dongfangwuquan.com/miniprogram` | 小程序配置、首页编排、课程上架、版本预览 |
| 网课小程序 -> API | `https://miniapi.dongfangwuquan.com` | 小程序专用 API，聚合课程、订单、学习数据 |
| 网课小程序 -> 认证 | `https://auth.dongfangwuquan.com` | 小程序登录、手机号绑定、统一身份 |

## 三、统一原则

- 只有后台可以进入管理能力，小程序不得直连后台页面。
- 官网负责公开展示和转化，学习行为统一进入小程序。
- 后台可以预览官网和小程序配置，但不再用 iframe 拼旧页面。
- 小程序只访问 `miniapi.dongfangwuquan.com` 与 `auth.dongfangwuquan.com`。
- 所有跨端链接统一从 `src/lib/platform-links.ts` 读取。

## 四、当前已接入页面

| 页面 | 接入内容 |
| --- | --- |
| 后台顶部栏 | 官网快捷入口 |
| 用户下拉菜单 | 官网、小程序配置 |
| 系统设置 | 三端链接矩阵、API 域名、认证中心、小程序 API |
| 首页总览 | 后台正式域名来源统一配置 |
