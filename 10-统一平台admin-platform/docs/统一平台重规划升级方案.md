# 伊娃东方舞统一平台重规划升级方案

## 1. 重新定位

新平台固定为：

```text
10-统一平台admin-platform
```

这是唯一继续开发的统一管理后台工程。

旧系统只作为：

```text
数据源
业务逻辑参考
页面交互参考
迁移适配对象
```

旧系统包括：

```text
03-学员管理系统/学员管理系统
04-网课系统开发计划
07-电商系统
09-财务系统
```

后续原则：

```text
不在旧系统里继续改主业务
不把旧页面 iframe 到新平台
不把多个后台拼在一起
不直接复制旧系统的混乱结构
```

## 2. 为什么要重新规划

之前推进速度和效果不满意的根本原因不是代码写得不够快，而是边界没有锁死：

```text
一边改旧系统
一边做新平台
一边补接口
一边迁数据
```

这会导致：

```text
主线分散
旧系统越改越重
统一平台没有成为真正主工程
功能看起来接上了，但架构仍旧分裂
```

现在必须改成：

```text
新平台为主
旧系统只读参考
通过适配层接入旧数据
逐步替换旧后台入口
```

## 4. 数据接入方式

不要让新平台直接散乱调用旧系统接口。

要统一为：

```text
旧系统 API / DB
        ↓
adapter 适配层
        ↓
统一领域模型
        ↓
新平台页面
```

适配层分为：

```text
member-adapter
order-adapter
offline-course-adapter
online-course-adapter
ecommerce-adapter
finance-adapter
```

统一模型：

```text
Member
MemberProfile360
Order
OrderItem
Course
OnlineSeries
Training
Product
Inventory
FinanceTransaction
PermissionRole
```
