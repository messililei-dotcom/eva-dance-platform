# admin.dongfangwuquan.com 访问恢复说明

## 当前诊断

2026-06-07 检查结果：

- `https://admin.dongfangwuquan.com/` 在浏览器中显示无法访问。
- `https://admin.dongfangwuquan.com/`、`https://www.dongfangwuquan.com/` 均出现 SSL 连接超时。
- 当前云服务器为 `8.138.227.61`，登录名为 `root`。
- 生产服务器密码不写入仓库或文档，需通过安全方式临时输入或从密码管理器读取。

这说明问题优先级不是前端页面代码，而是生产服务器访问链路：

1. 云服务器安全组/防火墙没有放行 80、443 或 22。
2. Nginx 未运行、证书配置异常，或反向代理没有指向当前后台端口。
3. PM2 中的 `admin-platform` 进程未正常监听 `3003`。
4. 旧部署文档仍有 `3000` 端口记录，可能导致反代端口错配。

当前工程的准生产配置以 `3003` 为准：

- `package.json`: `next start -p 3003`
- `ecosystem.config.js`: `PORT=3003`
- 审计记录：`admin-platform` 运行端口为 `3003`

## 服务器快速恢复

在云服务器执行：

```bash
cd /www/wwwroot/dongfangwuquan/admin-platform
bash scripts/production-healthcheck.sh
```

如果 PM2 未运行或本地 `3003` 不通：

```bash
cd /www/wwwroot/dongfangwuquan/admin-platform
npm ci
npm run build
pm2 start ecosystem.config.js --update-env
pm2 save
curl -I http://127.0.0.1:3003/login
```

如果本地 `3003` 正常但外网域名不通：

```bash
sudo cp deploy/admin-platform.nginx.conf /etc/nginx/conf.d/admin-platform.conf
sudo nginx -t
sudo systemctl reload nginx
curl -I https://admin.dongfangwuquan.com/login
```

如果 `nginx -t` 提示证书路径不存在，先重新签发或把配置中的证书路径改为服务器实际证书路径。
