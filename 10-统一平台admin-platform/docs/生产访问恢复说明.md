1. 云服务器安全组/防火墙是否放行 80、443。
2. Nginx 是否运行、证书是否有效、反向代理是否指向当前应用端口。
3. PM2 中的 `admin-platform` 是否正常监听 `3003`。
4. 配置是否误用旧端口 `3000`。

当前工程的准生产配置以 `3003` 为准：

- `package.json`: `next start -p 3003`
- `ecosystem.config.js`: `PORT=3003`
- 审计记录：`admin-platform` 运行端口为 `3003`

## 服务器快速恢复

在云服务器执行：

```bash
cd /www/wwwroot/dongfangwuquan/admin-platform
bash scripts/production-healthcheck.sh
```

如果 PM2 未运行或本地 `3003` 不通：

```bash
cd /www/wwwroot/dongfangwuquan/admin-platform
npm ci
npm run build
pm2 start ecosystem.config.js --update-env
pm2 save
curl -I http://127.0.0.1:3003/login
```

如果本地 `3003` 正常但外网域名不通：

```bash
sudo cp deploy/admin-platform.nginx.conf /etc/nginx/conf.d/admin-platform.conf
sudo nginx -t
sudo systemctl reload nginx
curl -I https://admin.dongfangwuquan.com/login
```

如果 `nginx -t` 提示证书路径不存在，先重新签发或把配置中的证书路径改为服务器实际证书路径。
