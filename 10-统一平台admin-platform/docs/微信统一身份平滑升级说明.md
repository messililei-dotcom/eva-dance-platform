# 微信统一身份平滑升级说明

## 目标

官网网站应用、小程序、服务号和微信小店都绑定在同一个微信开放平台账号后，
同一微信用户通过 `UnionID` 归入一个平台会员 `Member.id`。各应用自己的
`OpenID` 分开保存在 `WechatIdentity`，不再互相覆盖。

## 平滑过渡规则

1. 原手机号验证码登录、小程序登录和旧会员令牌继续有效。
2. `Member.wx_openid`、`Member.wx_unionid` 暂时保留，兼容旧页面和旧接口。
3. 新登录同时写入 `WechatIdentity`；旧字段只作为兼容镜像。
4. 同一 `UnionID` 可以关联网站、小程序、服务号和小店的多个 OpenID。
5. 两个非空且不同的 UnionID 禁止自动合并，进入人工核对。
6. 历史数据迁移只补充身份映射，不删除会员、不覆盖业务数据。
7. 所有绑定和会员归并动作写入 `WechatIdentityAudit`。

## 应用类型

| channel | 用途 |
| --- | --- |
| `website` | 开放平台网站应用，电脑微信扫码登录 |
| `official_account` | 服务号网页授权 |
| `mini_program` | 微信小程序 `wx.login` |
| `store` | 微信小店订单或会员身份同步 |

## 生产环境变量

官网：

```text
NEXT_PUBLIC_WECHAT_QR_ENABLED=true
WECHAT_QR_APP_ID=网站应用 AppID
WECHAT_QR_APP_SECRET=重置后的新 Secret
WECHAT_OFFICIAL_APP_ID=服务号 AppID
WECHAT_OFFICIAL_APP_SECRET=服务号 Secret
ADMIN_SESSION_SECRET=与统一平台相同的随机密钥
```

统一平台：

```text
WECHAT_MINIAPP_APP_ID=小程序 AppID
WECHAT_MINIAPP_SECRET=小程序 Secret
WECHAT_IDENTITY_SYNC_SECRET=小店/服务号服务器同步专用随机密钥
```

Secret 不得写入源码、前端环境变量或提交记录。

## 小店同步入口

`POST /api/wechat/identity/sync`

只供服务器调用，必须携带：

```text
X-Wechat-Identity-Secret: <WECHAT_IDENTITY_SYNC_SECRET>
```

请求正文示例：

```json
{
  "channel": "store",
  "appId": "小店所属应用 AppID",
  "openid": "小店接口返回的 OpenID",
  "unionid": "小店接口返回的 UnionID",
  "externalRef": "订单号"
}
```

接口不会根据昵称自动合并，也不会根据未验证手机号自动合并。

## 上线顺序

1. 备份生产数据库。
2. 部署统一平台代码，保持旧登录入口不变。
3. 设置新 Secret 和各应用 AppID，重启服务。
4. 部署官网并启用扫码登录。
5. 先用内部测试微信验证四端 UnionID，再逐步开放入口。
6. 观察 `WechatIdentityAudit` 和冲突记录，确认后再处理历史重复会员。
