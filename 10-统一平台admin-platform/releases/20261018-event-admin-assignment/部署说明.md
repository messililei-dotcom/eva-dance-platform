# 赛事管理员分配部署包

状态：已准备，未部署。

范围：赛事新建、编辑时由超级管理员选择一名启用的赛事管理员，服务端验证分配权限，沿用 owner_user_id 归属隔离。未选择时保持现有逻辑。不创建账号、不设置密码、不修改现有赛事数据。

部署前需将包内文件与服务器现有源码逐个比较并合并，备份现有源码、构建产物和数据库；不得整库覆盖。基于线上当前源码创建隔离构建，只合入本包改动。运行权限测试、源码类型检查及生产构建；成功后保留旧构建，切换并重载 admin-platform。失败时恢复旧源码和构建。

验收：超级管理员新建/编辑表单可选启用赛事管理员；普通赛事管理员看不到分配控件，直接提交分配请求返回403；保存后重新加载可见分配结果；受限账号只可访问所属赛事。使用隔离测试数据验证，未经授权不要改写真实赛事归属。

manifest.json 记录源码 SHA-256。此前本地7项权限测试与排除旧生成缓存后的源码类型检查通过。当前会话因后台地址操作限制，未做线上部署或验收。
