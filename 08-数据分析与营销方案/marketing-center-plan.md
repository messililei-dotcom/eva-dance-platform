## 2. 营销工具模块

### 2.1 优惠券系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **券类型** | 满减券、折扣券、直减券、免邮券、新人专享券 | P1 |
| **发放方式** | 手动领取、自动发放（事件触发）、批量导入、限时抢 | P1 |
| **使用规则** | 适用商品/课程、满减门槛、有效期（绝对/相对）、每人限领 | P1 |
| **叠加规则** | 是否可叠加、叠加优先级、与会员折扣互斥/并行 | P1 |
| **领取限制** | 每人限领、每日限领、总量上限 | P2 |
| **券码生成** | 批量生成唯一券码（支持导入/导出），用于线下分发 | P2 |
| **效果追踪** | 领券数、核销数、核销率、带动GMV、拉新数 | P1 |

**推荐玩法（伊娃东方舞场景）**

| 玩法 | 目标 | 细则 |
|------|------|------|
| 🔥 **新人专享券** | 新注册→首单转化 | 注册即送¥50满200减券，有效期7天 |
| 🔥 **完课奖励券** | 提升完课率 & 复购 | 完成某课程后自动发放下一课程¥20券 |
| 🔥 **分享有礼券** | 社交裂变 | 分享课程/活动到朋友圈获得¥10券 |
| 🔥 **生日券** | 情感维系 | 学员生日月自动发放全品类¥30券 |

### 2.2 满减/满折系统

| 规则类型 | 策略示例 | 适用场景 |
|----------|----------|----------|
| 阶梯满减 | 满200减20 / 满500减60 / 满1000减150 | 课程打包购买 |
| 满折 | 满300享9折 / 满500享85折 | 电商+课程跨品类 |
| 满赠 | 满399送舞蹈袜 / 满699送定制练功服 | 开学季、周年庆 |

### 2.3 拼团系统

| 功能 | 说明 | 适用场景 |
|------|------|----------|
| **双人团** | 2人成团，团长价=9折 / 团员价=95折 | 线上录播课 |
| **三人团** | 3人成团，团长价=85折 | 直播训练营 |
| **老带新团** | 要求至少1名新用户参团 | 拉新+转化 |
| **阶梯团** | 10-49人 → 95折 / 50-99人 → 9折 / 100+ → 8折 | 线下集训早鸟 |

### 2.4 秒杀/限时购

| 功能 | 说明 |
|------|------|
| 限时秒杀 | 指定时间区间（如今晚20:00-22:00）特价 |
| 限量秒杀 | 限量XX份（前10名半价） |
| 整点秒杀 | 每天12:00/20:00两个时段开抢 |
| 预告功能 | 提前24/12/3小时推送秒杀预告 |

### 2.5 积分体系（与会员体系联动）

| 功能 | 说明 |
|------|------|
| **积分获取** | 消费（1元=1分）、签到（每日5分）、分享（10分/次）、评论课程（20分/次） |
| **积分消耗** | 兑换优惠券（100分=¥10券）、兑换实物（舞蹈服等）、抵扣部分金额 |
| **积分有效期** | 获取后180天过期，到期前30天发送提醒 |
| **积分商城** | 独立页面展示可兑换商品/券，积分+现金混合支付 |

## 3. CRM 客户分层策略

### 3.1 客户标签体系

**基础属性标签（自动打标）**

| 标签大类 | 具体标签 | 数据来源 |
|----------|----------|----------|
| 身份 | 新学员 / 老学员 / 体验课学员 / VIP学员 | 注册信息+购买记录 |
| 课程偏好 | 东方舞初级 / 芭蕾形体 / 道具舞 / 编舞课 | 购课记录 |
| 消费能力 | ¥0-199 / ¥200-499 / ¥500-999 / ¥1000+ | 历史消费总额 |
| 购买频次 | 首购 / 复购1次 / 复购2次+ / 高频会员 | 订单数 |
| 活跃状态 | 7日活跃 / 30日活跃 / 90日活跃 / 沉睡(90天+) | 登录+行为数据 |
| 渠道来源 | 公众号 / 小红书 / 抖音 / 线下门店 / 老带新 | 注册来源追踪 |

**行为标签（AI/规则自动打标）**

| 标签 | 触发条件 | 营销含义 |
|------|----------|----------|
| 🛒 购物车放弃者 | 加入购物车但24h未支付 | 需要优惠券挽回 |
| 📖 高完课学员 | 完课率>80% | 高价值用户，推荐进阶课 |
| ⏸️ 中途弃课者 | 课程进度<30%且7天未学习 | 需要关怀+鼓励 |
| 🏷️ 价格敏感型 | 仅购买折扣/秒杀课程 | 用券/拼团转化 |
| 🎁 高分享型 | 月分享课程>5次 | 潜在KOC，可发展分销员 |
| 📞 咨询未购 | 详情页停留>3min + 咨询但未下单 | 需要人工跟进+专属优惠 |

### 3.2 RFM 分层模型

基于伊娃东方舞场景调整的 RFM 模型：

| R（最近购买） | F（购买频次） | M（消费金额） | 等级 | 策略 |
|---------------|---------------|---------------|------|------|
| 近30天 | ≥3次 | ¥2000+ | S级·超级会员 | VIP服务+推荐官邀请+新品内测 |
| 近30-60天 | 2次 | ¥500-1999 | A级·高价值 | 推送课程更新+社群+复购券 |
| 近60-90天 | 1次 | ¥200-499 | B级·成长型 | 交叉推荐+会员升级引导 |
| 近90-180天 | 1次 | ¥0-199 | C级·低价尝鲜 | 拼团/低价体验课引流 |
| >180天 | 0次 | ¥0 | D级·已流失 | 唤醒短信+大额召回券+问卷 |
| 近30天新注册 | 0次 | ¥0 | N级·新用户 | 新人礼包+引导购课+7天跟进 |

### 3.3 客户分组与营销匹配

| 客户分组 | 典型人数占比 | 推荐营销策略 | 触达渠道 |
|----------|-------------|-------------|----------|
| 超级会员 | 5% | 1对1服务、新品首发内测、推荐官 | 私信+专属群 |
| 活跃付费学员 | 25% | 课程升级、年卡推荐、老带新权益 | 公众号+个人号 |

| 沉睡学员 | 25% | 唤醒优惠券、低价体验课、活动邀请 | 短信+电话（高价值） |

| 咨询未购 | 5% | 限时优惠、试听课邀请、顾问跟进 | 私信+电话 |

## 4. 自动化营销流程

### 4.1 自动化营销引擎功能需求

| 功能模块 | 说明 | 优先级 |
|----------|------|--------|
| **触发条件** | 注册/首购/复购/登录/弃购/课程进度/会员到期/沉睡定义等 | P1 |
| **动作配置** | 发放优惠券、发送推送、更新标签、分配跟进任务 | P1 |
| **时间延迟** | 即时触发 / 延迟N小时/天触发 / 定时触发 | P1 |
| **条件分支** | 根据用户标签/行为执行不同路径 | P2 |
| **频率限制** | 单用户N天最多触发X次，避免骚扰 | P1 |
| **A/B测试** | 同一流程中分流测试不同文案/动作 | P2 |
| **效果统计** | 触达人数、转化人数、带来的GMV | P1 |

### 4.2 核心自动化流程设计

#### 流程1：新学员欢迎旅程

```
触发条件：用户完成注册
──→ 立即：发放新人礼包（¥50满减券 + 免费体验课）
──→ 延时24h：发送推送"如何开始你的第一堂东方舞课"
──→ 延时72h：检查是否已购课
    ├── 是 → 发送"恭喜开始学习！" + 完课奖励说明
    └── 否 → 发送限时优惠提醒 + 热门课程推荐 + 分享老学员故事
──→ 延时7天：检查是否完成首购
    ├── 是 → 进入"新学员成长旅程"
    └── 否 → 发送专属优惠券 + 1对1咨询引导
```

#### 流程2：购物车放弃挽回

```
触发条件：用户将课程加入购物车后24小时未支付
──→ 立即：发送推送"您还有课程在等待您 💃" + ¥20专属券
──→ 延时48h：发送第二波推送 + 限时提醒（仅剩X张）
──→ 延时72h：未购买 → 客服人工跟进（仅限高客单价课程>¥300）
──→ 延时7天：仍无动作 → 打标"购物车放弃未挽回"
```

#### 流程3：沉睡唤醒

```
触发条件：用户连续90天无登录行为
──→ 立即：发送"好久不见，专属回归礼已为您准备"（¥30大额券）
──→ 延时7天：未登录 → 发送新课程/活动推荐短信
──→ 延时14天：未登录 → 发送"老学员专属活动邀请"
──→ 延时30天：仍未登录 → 发送高价值用户电话回访（仅消费¥500+用户）
    ├── 回访有效 → 打标"已唤醒"
    └── 回访无效 → 打标"已流失"
```

#### 流程4：完课 → 复购引导

```
触发条件：用户首次完成某课程>80%进度
──→ 立即：发送"恭喜完成！🎉" + 完课证书/勋章（社交分享入口）
──→ 延时24h：推荐同系列进阶课程 + 完课专享¥20券
──→ 延时7天：推送学员真实成长故事 + 后续课程组合优惠
──→ 延时30天：推送会员升级权益说明
```

#### 流程5：续费提醒旅程

```
触发条件：会员到期前30天
──→ 到期前30天：推送"您的会员即将到期" + 续费专属折扣
──→ 到期前14天：推送续费权益对比 + 限时优惠倒计时
──→ 到期前7天：发送限时折扣码 + 客服跟进
──→ 到期日：推送"会员已到期" + 最后一次优惠机会
──→ 到期后7天：检查是否续费
    ├── 是 → 发送"欢迎续费！" + 新会员权益指南
    └── 否 → 打标"会员已流失" + 沉睡唤醒流程
```

## 5. 活动管理模块

### 5.1 活动类型模板

| 活动类型 | 模板组件 | 推荐配置 |
|----------|----------|----------|
| **季度大促** | 满减+秒杀+积分翻倍 | 每年3/6/9/12月 |
| **周年庆** | 全场折扣+拼团+裂变卡片 | 每年4月 |
| **新课首发** | 限时秒杀+分享有礼 | 每月1-2次 |
| **会员日** | 双倍积分+会员专享价 | 每月15日 |
| **节日营销** | 主题海报+节日限定券 | 七夕/中秋/国庆/新年 |

### 5.2 活动创建流程

```
创建活动 → 选择模板/从空白创建
    → 配置规则（商品/折扣/时间/人群圈选）
    → 预览效果（预估参与人数、GMV影响）
    → 提交审批（运营→管理层）
    → 自动排期上线（支持定时发布）
    → 实时数据看板（参与人数/成交/曝光/转化）
    → 活动结束 → 效果报告自动生成
```

### 5.3 活动效果评估指标

| 指标 | 计算方式 | 参考值 |
|------|----------|--------|
| 活动GMV | 活动期间指定商品总成交额 | — |
| 增量GMV | 活动GMV - 非活动期日均GMV × 活动天数 | >30% |
| ROI | (活动GMV - 活动成本) / 活动成本 | >5 |
| 拉新占比 | 新用户成交数 / 总成交数 | >15% |
| 优惠券核销率 | 核销券数 / 发放券数 | >35% |

## 6. 营销数据分析

### 6.1 核心分析视图

| 仪表板 | 包含内容 |
|--------|----------|
| **营销总览** | 活动数量、优惠券发放/核销、总投入、总收益、整体ROI |
| **渠道效果** | 各渠道曝光、点击、转化、CAC、ROI对比 |
| **人群分析** | 各客户分层的参与率、转化率、客单价 |
| **优惠券分析** | 各类券的领取率、核销率、带动GMV、券效 |
| **活动归因** | 用户最终下单前接触的触点序列（首/末/多触点归因） |

### 6.2 归因模型建议

| 模型 | 场景 | 说明 |
|------|------|------|
| 末次归因 | 简单场景 | 最后一次触点获得100%功劳 |
| 线性归因 | 均衡评估 | 所有触点平均分配 |
| 时间衰减归因 | 长期营销 | 越接近转化的触点权重越高 |
| U形归因（40-20-40） | 综合评估 | 首次40% + 中间20% + 末次40% |

**建议默认采用**：时间衰减归因（兼顾短期转化刺激和长期品牌影响）
