# Dashboard 数据指标方案

> 伊娃东方舞统一数字化运营平台 · 管理驾驶舱 KPI 体系
> 更新日期：2026-05-23

---

## 1. Dashboard 核心设计原则

| 原则 | 说明 |
|------|------|
| **分层呈现** | 管理层/运营层/执行层各有独立视图 |
| **趋势优先** | 所有核心指标均展示7日/30日趋势线（环比/同比） |
| **异常预警** | 关键指标波动>15%自动标红+推送通知 |
| **下钻能力** | 高层级指标均可下钻到详情页 |

## 2. 管理层 Dashboard（每日必看）

### 全局健康指标卡（顶部5卡）

| 指标 | 定义 | 口径 | 预警线 | 展示形式 |
|------|------|------|--------|----------|
| **GMV（总成交额）** | 当日所有订单收入总和 | 实付金额 | 环比-20% | 大数字+趋势箭头+7日折线 |
| **新增注册用户** | 当日注册学员数 | 去重手机号 | 环比-30% | 大数字+同比指标 |
| **活跃学员数** | 当日产生行为的学员数 | 登录/看课/下单任一项 | 环比-25% | 柱状图（7日对比） |
| **整体转化率** | 访问→支付的成功率 | 支付单数/课程页UV | <2%标红 | 百分比+目标线对比 |
| **营收完成率** | 当日营收 vs 月度目标进度 | 已营收/目标营收 | <60%月中期 | 进度条+倒计时 |

## 4. 数据可视化规范

### 4.1 图表类型映射

| 分析场景 | 推荐图表 | 备注 |
|----------|----------|------|
| 趋势对比（时间序列） | **折线图** | 7日/30日/同比周期 |
| 多品类对比 | **柱状图 / 条形图** | 按销量/金额倒序 |
| 构成占比 | **饼图 / 环形图** | 不超过6个分类 |
| 多维度交叉 | **堆叠柱状图** | 如：各渠道×转化率 |
| 连续进度 | **仪表盘 / 进度条** | 设定目标值 |
| 流程转化 | **漏斗图** | 必须标注每一步流失率 |
| 人群/商品分布 | **热力图** | 如：时段×品类GMV |
| 散点分布 | **散点图** | 如：客单价×复购率 |

### 4.2 通用规范

- **时间轴**：统一 YYYY-MM-DD 格式，左旧右新
- **货币单位**：统一 ¥ 符号 + 千位分隔（¥12,345）
- **百分比**：保留1位小数（15.3%）
- **大数字**：≥10,000 显示为"万"单位（1.2万）
- **配色**：主色 #E84393（品牌粉），涨绿色 #27AE60，跌红色 #E74C3C
- **空数据占位**：`--` 而非 0

### 4.3 异常展示规范

| 触发条件 | 视觉效果 | 附加动作 |
|----------|----------|----------|
| 指标环比下降>20% | 指标卡红色背景 + ↓ 图标 | 自动推送到管理群 |
| 指标环比下降10%–20% | 指标卡橙色背景 + ↓ 图标 | — |
| 指标偏离月度目标>15% | 进度条红色半段 | 推送周报预警 |
| 退费率月环比上升>30% | 红线标绘 | 触发退款原因分析 |

## 6. 数据刷新与推送策略

| 类别 | 刷新频率 | 推送方式 | 推送对象 |
|------|----------|----------|----------|
| 关键指标卡 | 实时（5分钟） | — | 首页自动刷新 |
| 趋势图表 | 日终（00:30） | — | 页面加载刷新 |
| 日度数据简报 | 每日 09:00 | 飞书机器人消息 | 管理层群 |
| 异常预警 | 实时 | 即时消息+飞书@ | 相关责任人 |
| 周报摘要 | 每周一 09:00 | PDF自动生成 | 管理层邮箱 |
| 月度经营报告 | 次月1日 09:00 | PDF+数据附件 | 全体核心成员 |
