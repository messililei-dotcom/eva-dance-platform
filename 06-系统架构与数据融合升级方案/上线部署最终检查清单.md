# 上线部署最终检查清单

**适用时间：** 上传服务器测试外网访问前  
**适用系统：** 官方网站、统一管理后台  

---

## 一、服务器端口规划

建议第一轮外网测试使用以下端口和反向代理：

```text
官方网站 Next.js        127.0.0.1:3001  -> https://dongfangwuquan.com
统一管理后台 Next.js    127.0.0.1:3003  -> https://admin.dongfangwuquan.com
```

课程、学员、电商、财务、小程序配置统一通过 `admin.dongfangwuquan.com` 下的模块路径访问，不再配置独立后台二级域名。

## 三、必须上传或备份的数据

学员管理系统必须保留：

```text
03-学员管理系统/学员管理系统/server/dance.db
03-学员管理系统/学员管理系统/uploads/
```

如果上传时数据库旁边存在 WAL 文件，也要一起处理：

```text
dance.db-wal
dance.db-shm
```

推荐上传前先在本机或服务器执行 SQLite checkpoint，让最新数据合并进 `dance.db`：

```bash
node -e "const Database=require('better-sqlite3'); const db=new Database('dance.db'); db.pragma('wal_checkpoint(TRUNCATE)'); db.close();"
```

## 四、生产环境变量

### 1. 统一管理后台

参考：

```text
10-统一平台admin-platform/.env.production
```

可以复制为服务器上的 `.env` 或 `.env.production`。服务启动时会自动读取这两个文件；同名的系统环境变量优先级更高。

必填：

```text
NODE_ENV=production
PORT=3000
JWT_SECRET=至少32位随机字符串
ALIYUN_ACCESS_KEY_ID=阿里云短信 AccessKey
ALIYUN_ACCESS_KEY_SECRET=阿里云短信 Secret
ALIYUN_SMS_SIGN_NAME=短信签名
ALIYUN_SMS_TEMPLATE_CODE=短信模板
SMS_PRODUCTION=true
```

首次部署如果数据库没有管理员，可以临时设置：

```text
CREATE_DEFAULT_USERS=true
DEFAULT_ADMIN_PASSWORD=强密码
```

管理员创建完成后建议改回：

```text
CREATE_DEFAULT_USERS=false
```

### 2. 官方网站

参考：

```text
02-官方网站工程设计/官方网站/.env.production.example
```

必须确认生产构建时不是本地地址：

```text
NEXT_PUBLIC_API_URL=https://admin.dongfangwuquan.com/api
STUDENT_API_URL=https://admin.dongfangwuquan.com/api
MANAGEMENT_API_BASE=https://admin.dongfangwuquan.com/api
MANAGEMENT_ORIGIN=https://admin.dongfangwuquan.com
```

## 八、当前必须关注的上线风险

1. 官网本地 `.env.local` 指向 `http://localhost:3000/api`，不要原样上传生产服务器。
2. 学员管理系统生产模式必须配置 `JWT_SECRET`，否则无法启动。
3. 学员短信登录依赖阿里云短信配置，缺少短信配置时验证码发送不可用。
4. `ecosystem.config.js` 已改为相对路径，但服务器路径仍需和上传目录保持一致。
5. SQLite 上传前要处理 WAL 文件，否则可能出现服务器数据不是最新状态。
6. 服务器防火墙、安全组、Nginx 反向代理和 HTTPS 证书需要同步配置。
