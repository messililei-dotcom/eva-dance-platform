## 一、整体架构总览

当前系统采用「单数据库 + 多服务」拓扑结构，4个后端系统共享同一份 dance.db。

```
dance.db (better-sqlite3 + WAL)
  ├─ 学员管理系统 (3000) - Express + JWT
  ├─ 电商系统 (3101) - HTTP原生
  ├─ 网课系统 (3002) - Express
  └─ 财务系统 (3201) - HTTP原生
  
admin-platform (3003) ← 官方网站 (3001)
```

## 二、核心发现

1. **4个系统共享同一数据库** - 统一平台的最大优势
2. **37张数据表**完整覆盖学员/课程/订单/电商/财务/权限
3. **统一认证、API网关、去除冗余**是三大核心任务
