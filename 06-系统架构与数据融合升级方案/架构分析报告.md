## 十、电商体系现状

### 10.1 电商数据存储

```
存储模式：JSON文件 + 主库双写
主文件：data/inventory-store.json
主库表：shop_products, shop_sales, shop_stock_logs
```

### 10.2 电商问题
- **👉 双存储风险：** 电商数据在 JSON 文件和数据库之间双向同步，存在不一致风险

### 17.3 权限实现建议

```javascript
// 当前 middleware/auth.js 已有 hasPermission() 函数，做简单位比对
// 建议新增支持角色继承：
function hasPermissionByRole(db, user, permCode) {
  if (!user) return false;
  if (['super_admin', 'principal'].includes(user.role)) return true;
  const row = db.prepare(`
    SELECT 1 FROM admin_user_roles aur
    JOIN role_permissions rp ON aur.role_id = rp.role_id
    JOIN permissions p ON rp.permission_id = p.id
    WHERE aur.user_id = ? AND p.code = ?
  `).get(user.id, permCode);
  return !!row;
}
```
