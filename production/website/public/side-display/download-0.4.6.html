Install and connect / 安装与连接

  1. Download and unzip the Mac app. Drag Side Display.app into Applications and open it. / 下载解压后，将程序拖入“应用程序”并打开。
  2. Allow Screen Recording in macOS Privacy & Security. Allow Accessibility for touch and keyboard control. / 在系统隐私与安全性中允许屏幕录制；需要触控和键盘操作时允许辅助功能。
  3. Open the receiver on an unlocked iPhone or iPad. Use a trusted USB data cable, or pair the devices on the same local network using the code in receiver Settings → Wireless Connection. / 打开手机或平板接收端，用可信数据线连接，或在同一本地网络下输入配对码。
  4. Choose Extended Display or Mirror Screen; refresh the connection from the receiver if needed. / 选择“扩展屏幕”或“实时屏幕”，需要时在接收端刷新连接。
